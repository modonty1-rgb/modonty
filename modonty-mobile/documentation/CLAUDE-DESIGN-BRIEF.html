== HARD RULES (non-negotiable) ==
- RTL everywhere: start = right. Back arrow points right. Progress/sliders fill from right. Action column on reels sits on the LEFT.
- No emoji anywhere. Line icons, one consistent set, one stroke weight.
- No blur / glassmorphism (Android performance). Floating bars are near-opaque solid + shadow.
- Contrast ≥ 4.5:1 for all text, both themes. Touch targets ≥ 48dp.
- No orphan word on its own line in headlines (balance the wrap).
- NEVER fabricate data: no star ratings (rating is null for all partners), hide zero counts (likes/comments = 0 → icon only), hide weak social proof (followers < threshold, views), mark partner-claimed stats as "أرقام تذكرها المؤسسة".
