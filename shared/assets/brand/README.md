# Shared brand assets

## `modonty-industries-mark.svg`

العلامة الرسمية المعتمدة للمجالات. ملف التصميم فقط؛ دمجه في React أو سجل الأيقونات
مسؤولية المنفّذ.

### عقد الدمج

- يُستخدم كـInline SVG حتى تصل إليه متغيرات الـtheme؛ لا يُستخدم `<img>` للنسخة الملونة.
- `--modonty-industries-body: hsl(var(--foreground))` للبوابات.
- `--modonty-industries-accent: hsl(var(--accent))` للماسة.
- ممنوع استبدال المتغيرات بـHex أو ألوان Tailwind مباشرة داخل المسار.
- بجانب نص «المجالات» يكون `aria-hidden`. إذا ظهر وحده، يأخذ الرابط اسمًا مثل
  `aria-label="استكشف المجالات"`.
- الحد الأدنى للنسخة ثنائية اللون `16px`، وهدف اللمس المستقل `44px` على الأقل.

قصة العلامة المنظمة موجودة في `modonty-industries-mark.story.json`، والقصة المختصرة
مضمّنة داخل SVG حتى تبقى ملازمة للأصل عند نقله.

## `modonty-partners-mark.svg`

العلامة الرسمية المعتمدة للشركاء: واجهة شركة بفتحتين مقوستين تصنعان إيقاع حرف `m`،
وماسة مدوّنتي عند القاعدة كحجر أساس. ملف التصميم فقط؛ دمجه في React أو سجل الأيقونات
مسؤولية المنفّذ.

### عقد الدمج

- يُستخدم كـInline SVG حتى تصل إليه متغيرات الـtheme؛ لا يُستخدم `<img>` للنسخة الملونة.
- `--modonty-partners-body: hsl(var(--foreground))` لواجهة المبنى.
- `--modonty-partners-accent: hsl(var(--accent))` للماسة.
- ممنوع استبدال المتغيرات بـHex أو ألوان Tailwind مباشرة داخل المسار.
- بجانب نص «الشركاء» يكون `aria-hidden`. إذا ظهر وحده، يأخذ الرابط اسمًا مثل
  `aria-label="استكشف الشركاء"`.
- الحد الأدنى للنسخة ثنائية اللون `16px`، وهدف اللمس المستقل `44px` على الأقل.
- لا تُنقل الماسة إلى أعلى المحور الأوسط ولا تُضاف نوافذ أو نقاط أخرى.

قصة العلامة المنظمة موجودة في `modonty-partners-mark.story.json`، والقصة المختصرة
مضمّنة داخل SVG حتى تبقى ملازمة للأصل عند نقله.
