🔴 التفاصيل والأدلة والتصحيح المقترح

1 · SEO Images — سقف بترتيب معكوس للغرض

admin/app/(dashboard)/seo-images/helpers/load-groups.ts:251

db.media.findMany({ select: MEDIA_SELECT, take: HARD_CEILING, orderBy: { createdAt: "desc" } })

القيمة: 500. ما يُقص: صور SEO قبل تشكيل مجموعات التشخيص. الترتيب: الأحدث أولاً، بينما الوصف يقول worst-first. القياس: 870 في الإنتاج مقابل 500، و370 غير مرئي (43%)؛ هذا رقم وارد في طلب التدقيق ولم أعد قياسه. اليوم: قد يرى المشرف أحدث 500 ويبحث عن أسوأ الصور فلا يجدها. بلا السقف: الأسوأ فعلاً أو صفحات عينة معلنة.

@@ مقترح فقط @@
- take: HARD_CEILING, orderBy: { createdAt: "desc" }
+ paginate deterministically; compute groups across all pages
+ or rank score in DB and return total + nextCursor

2 · الأرشيف العام — سقف 300 يقطع القراءة والزحف

modonty/lib/articles/archive/get-articles-archive.ts:152

take: MAX_ARCHIVE_ARTICLES حيث MAX_ARCHIVE_ARTICLES = 300. الصفحات اللاحقة تأخذ slice من النتيجة المحدودة؛ لا count ولا totalPages. اليوم: القارئ وجوجل يصلان إلى 300 كأنها المكتبة كلها. بلا السقف: كل مقال منشور ضمن skip/take أو cursor. القياس: غير مقيس.

@@ مقترح فقط @@
- take: MAX_ARCHIVE_ARTICLES
+ skip: (page - 1) * ARCHIVE_PAGE_SIZE, take: ARCHIVE_PAGE_SIZE
+ Promise.all([findMany(...), count({ where })])

3 · بحث الشركاء — العدد المكتوب ليس عدد النتائج

4 · Mobile console — ثلاث عدّادات تُقص قبل أن تُحسب

console/app/api/mobile/v1/articles/route.ts:28 · notifications/route.ts:43 · bookings/route.ts:43

كلها take: 100، ثم articles.length أو rows.filter(...).length. هذا فخ القص قبل العد: قائمة القرار، غير المقروء، والمفتوح قد تكون ناقصة مع شارة تؤكد الخطأ. القياس: غير مقيس.

@@ مقترح فقط @@
- const rows = await findMany({ take: 100 }); const count = rows.filter(...).length
+ const [page, count] = await Promise.all([findMany({ take, cursor }), db.model.count({ where })])

ما لم يُقَس

لم أنفذ أي قراءة من قاعدة الإنتاج. لذلك كل 🔴 غير SEO Images مكتوب أمامه «غير مقيس»، لا تخمين. رقم SEO Images الوحيد (870/500/370) مصدره نص طلب التدقيق نفسه.

القياس السليم لكل بند: count({ where: نفس شروط الاستعلام }) في الإنتاج، ثم سجل actual / cap / hidden / percent. لا تستخدم طول المصفوفة المقصوصة كبديل للـcount.

ترتيب الإصلاح

  1. الأرشيف العام والبحث: خسارة اكتشاف القارئ والزحف.
  2. SEO Images وReference SEO وAnalytics: قرار إداري على عينة.
  3. Mobile decision/notifications/bookings: العميل يتصرف على عداد ناقص.
  4. المعرض/الريلز/الفواتير/المهام: cursor أو pagination وعبارة X من Y، لا مجرد رفع الرقم.
