١ · الفرق بين الاتنين — في سطرين

GA4 = الدفتر اللي بيتسجّل فيه كل حاجة.

GTM = ساعي البريد اللي بيوصّل الخبر للدفتر.

ممكن توصّل الخبر بنفسك بلا ساعي — وده اللي بنعمله في نصّ الأحداث عندنا. وهنا بالظبط بدأت المشكلة.

٢ · الزائر عندنا بيتسجّل من طريقين مختلفين

٣ · إيه الـ«هويّة» دي ولماذا هي أهمّ حاجة

GA4 مش شايف اسمك ولا وشّك. هو بيشوف رقم واحد بس اسمه client_id — رقم عشوائي محفوظ في كوكي على متصفّح الزائر. ده اللي بيخلّي جوجل يقول «الشخص ده فتح المقال، وبعدين راح لصفحة التسجيل، وبعدين سجّل».

عندنا رقمان مش رقم واحد:

الطريقالكوكيمين بيكتبه
سيرفرناmdy_vidكودنا
GTM_gaجوجل

الكود بيحاول يوحّدهم: يقرا _ga الأول وياخد الرقم منه، ولو مالقاهوش يعمل mdy_vid. الفكرة صح — لكنها ما بتشتغلش، والسبب في القسم اللي بعده.

٥ · «صفحة الهبوط» وليه ٦٩٪ منها فاضية

صفحة الهبوط = أول صفحة فتحها الزائر في الزيارة. جوجل بياخدها من أول page_view في الجلسة — مش من أي حدث تاني.

الهويّة الوهميّة عندها web_vitals بس، وما عندهاش page_view أبداً (لأن ده بيجي من GTM بالهويّة التانية). فجوجل يلاقي جلسة بلا أول صفحة، فيكتب (not set).

٦ · ليه ده يخرب كل رقم عندك

«نسبة الارتداد عالية»

٦٩٪ من الجلسات وهميّة، عمرها 0s، وما فتحتش ولا صفحة. جوجل بيعدّها ارتداد. الرقم مضخّم، والمشكلة في العدّاد مش في الزوّار.

«نسبة التحويل ضعيفة»

٢١ تسجيلاً مقسومة على مستخدمين متضخّمين ٤ أضعاف. الحقيقة أحسن أربع مرّات من اللي شايفه.

«مش عارف الناس جاية منين»

٦٩٪ من الجلسات بلا صفحة هبوط، يعني بلا مصدر معروف. تقرير المصادر عندك ناقص ثلثيه.

ما قدرتش أعيد إنتاج الـ 0.54. قياسي على نت سريع، وClarity بيقيس زوّاراً حقيقيين ٥٩٪ منهم على الجوّال. محاولة خنق الشبكة رجعت Not allowed، وPageSpeed API رجعت 429 بلا مفتاح. محجوب على مفتاح PageSpeed أو جلسة Clarity جديدة.

أكبر قفزة مسكتها: عنصر «اسأل مودو» بيتحرك ٦٩١ بكسل عند 799ms على الرئيسية.

// modonty/lib/analytics/visitor-cookie.ts:35-38
function parseGaCookieClientId(gaCookie: string): string | null {
  const match = gaCookie.match(/^GA\d+\.\d+\.(\d+\.\d+)$/);
  return match ? match[1] : null;
}

الفكرة صحيحة والتنفيذ غير رسمي. جوجل ما وثّقش قراءة الكوكي بالـregex — وثّق gtag('get'). وصيغة الكوكي تفصيل داخلي قابل للتغيير بلا إشعار. والأهم: الكوكي ما بيبقاش موجود أصلاً وقت أول حدث (مقيس فوق).

أ · مكوّن صغير يقرأ الهويّة بالـAPI الرسمي ويحفظها في كوكي يقراه السيرفر:

// modonty/app/layout/components/gtm/GaIdentityBridge.tsx  — جديد
"use client";
import { useEffect } from "react";

/**
 * Reads the client_id and session_id from gtag using Google's DOCUMENTED
 * `gtag('get', …)` API, then parks them in a cookie the server reads.
 *
 * Why not parse the `_ga` cookie: Google documents this API, not the cookie
 * format — and the cookie does not exist yet when our first event fires
 * (measured: first beacon at 1.255s, gtag requested at 2.083s).
 */
export function GaIdentityBridge({ measurementId }: { measurementId: string }) {
  useEffect(() => {
    const g = (window as { gtag?: (...a: unknown[]) => void }).gtag;
    if (!g) return;
    g("get", measurementId, "client_id", (cid: string) => {
      g("get", measurementId, "session_id", (sid: string) => {
        if (!cid) return;
        // Not httpOnly on purpose: the value is an anonymous analytics id, and
        // the client is the only place that can obtain it.
        document.cookie =
          `mdy_ga=${cid}|${sid ?? ""}; path=/; max-age=63072000; SameSite=Lax; Secure`;
      });
    });
  }, [measurementId]);
  return null;
}

// modonty/app/layout/components/gtm/WebVitals.tsx — تعديل
// Hold metrics until the identity bridge has parked `mdy_ga`, so no beacon
// creates a phantom user. Measured gap: first metric 1.255s, gtag 2.083s.
const queue: string[] = [];
let flushed = false;

function ready() {
  return typeof document !== "undefined" && /(^|;\s*)mdy_ga=/.test(document.cookie);
}

function flush() {
  if (flushed) return;
  flushed = true;
  for (const body of queue.splice(0)) send(body);
}

function send(body: string) {
  try {
    if (navigator?.sendBeacon) navigator.sendBeacon("/api/track/web-vitals", body);
    else fetch("/api/track/web-vitals", { method: "POST", body, keepalive: true }).catch(() => {});
  } catch {}
}

// in useReportWebVitals:
if (ready()) send(body);
else {
  queue.push(body);
  // A ceiling, not a promise: if gtag is blocked by an ad blocker the metric
  // still ships — a phantom user is better than a lost measurement.
  setTimeout(flush, 4000);
}
