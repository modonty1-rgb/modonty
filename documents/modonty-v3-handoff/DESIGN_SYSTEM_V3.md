# Modonty Design System — v3.0

> Single Source of Truth للتصميم في كل حزم المونوريبو (home / beta / admin).
> v3 = اختصار v2 + إصلاحات تدقيق الموبايل (يوليو 2026) + إعادة هيكلة التنقل (الصناعات أولًا + مدونتي Featured).
> الجمهور: المستخدم السعودي، موبايل أولًا (+85% من الزيارات).

---

## 1. Brand Essence

- الشخصية: منصة نشر عربية احترافية — هادئة، تحريرية، موثوقة (روح LinkedIn بهوية مدونتي).
- الثقة عنصر تصميم أساسي: شارة «موثّق من مدونتي»، الأثر الرقمي بأرقام حقيقية، المصادر.
- عربية أولًا: أي نص يظهر للزائر يكون عربيًا. الإنجليزية للأكواد والمعرّفات فقط.
- قاعدة ذهبية للموبايل: **طبقة عائمة واحدة كحد أقصى في أي شاشة**.

## 2. Design Tokens

### 2.1 Colors — Light

| Token | Value | Usage |
|---|---|---|
| `--background` | `#f3f2ef` | خلفية الصفحة (رمادي دافئ) |
| `--card` | `#ffffff` | البطاقات |
| `--border` | `#e0e0de` | حدود خفيفة |
| `--primary` | `hsl(240 100% 59%)` ≈ `#2E2EFF` | **الإنديجو الحالي في اللايف — معتمد** |
| `--primary-hover` | `hsl(240 100% 50%)` | hover |
| `--foreground` | `#000000` | النص الأساسي |
| `--muted-foreground` | `#666666` | نص ثانوي (لا أفتح من هذا للنص المقروء) |
| `--success` | `#16a34a` | نجاح + زر واتساب حصريًا |
| `--warning` / `--destructive` | `#f59e0b` / `#ef4444` | تنبيه / حذف |
| `--featured` | `#f0ecff` bg + `--primary` border | **جديد: خلفية بطاقة مدونتي المميزة والمحتوى المثبّت** |

### 2.2 Colors — Dark

**قرار معتمد: الداكن هو الافتراضي** (هوية مدونتي). خلفية `222 84% 5%` (كحلي داكن، ليس أسود صافيًا)، بطاقات أفتح درجة لعمق بصري، `--primary: hsl(240 100% 65%)` ≈ `#4D4DFF` للوضوح على الداكن. الوضع الفاتح يبقى متاحًا بالتبديل + `prefers-color-scheme`. شرط إلزامي: تباين AA (4.5:1) لكل النصوص على الداكن — خصوصًا النص الثانوي `--muted-foreground` لا يقل عن `hsl(215 20% 70%)`.

### 2.3 Typography

- الخط: `Tajawal` للعربية، system stack للاتينية. `font-feature-settings: 'rlig' 1, 'calt' 1`.
- **حدود دنيا جديدة (من التدقيق):** لا نص مقروء تحت **12px**، ولا label تفاعلي تحت **13px**. ممنوع استخدام 9–11px نهائيًا (كانت منتشرة في الإحصاءات وأزرار التفاعل).

| Element | Size | Weight | ملاحظات |
|---|---|---|---|
| H1 | 28–32px | 700 | عنوان الصفحة (واحد فقط لكل صفحة — يوجد حاليًا H1 مكرر في صفحة العميل) |
| H2 | 22–24px | 600 | أقسام |
| H3 | 18–20px | 600 | عناوين البطاقات |
| Body | 16px / line-height 1.8–1.9 | 400 | نص المقال |
| Small | 14px | 400 | ميتاداتا |
| Caption | 12px (الحد الأدنى) | 400 | طوابع زمنية |

### 2.4 Numerals & Bidi (جديد — إلزامي)

- نظام أرقام واحد عبر المنصة: **مشرقية ٠١٢٣ للنصوص والتواريخ** (`Intl.NumberFormat('ar-SA')`)، لاتينية للمعرّفات التقنية فقط. ممنوع خلط ٢٠٢٦ مع 2022 في نفس الصفحة.
- أي مقطع لاتيني داخل جملة عربية يُغلّف بـ `<bdi>` أو يُفصل بمسافة (يصلح كسور «MEPالعمود الفقري» و«والتكيفHVAC؟»).
- الروابط تُعرض داخل عنصر `dir="ltr"` مستقل (يصلح «/https://creativecommons...»).
- التعريب الكامل للقيم النظامية: Giza→الجيزة، medium→متوسط، One-Person Company→مؤسسة فردية، نبذة الكاتب بالعربية.

### 2.5 Spacing / Radius / Shadows

- شبكة 8px كما في v2. بطاقة: padding 16px، فجوة 12–16px موبايل و24px ديسكتوب.
- Radius: 8px بطاقات، 6px أزرار، 12px مودالات، **20px chips**.
- Shadows: خفيفة فقط (`shadow-sm` → `hover:shadow-md`). ممنوع الظلال الثقيلة.

### 2.6 Z-Index Layers (جديد — يحل فوضى التراكب)

| Layer | z | العناصر |
|---|---|---|
| 10 | sticky header (56px) | الهيدر فقط |
| 20 | شريط أقسام الصفحة اللاصق | يختفي عند النزول ويظهر عند الصعود (auto-hide) |
| 30 | Bottom action bar | **واحد فقط، يحتوي واتساب داخله** |
| 50 | Modals / Sheets | فوق الكل |

قواعد: المحتوى يأخذ `padding-bottom` بارتفاع الشريط السفلي (حاليًا يغطي «آراء العملاء»). زر الدردشة/واتساب العائم يُدمج في الشريط السفلي — لا أزرار عائمة إضافية.

## 3. Mobile Rules (غير قابلة للتفاوض)

1. أهداف اللمس ≥ **44×44px** مع 8px بين الأهداف (الفوتر والوسوم وأيقونات السوشال حاليًا 14–26px).
2. حد أقصى **153px → 96px** للعناصر الثابتة أثناء القراءة: هيدر (auto-hide) + شريط سفلي واحد.
3. صفحة المقال بعد المتن: 3 بطاقات «اقرأ أيضًا» كحد أقصى + «عرض المزيد». (حاليًا 14+ بطاقة وطول ~12,600px).
4. صندوق التحويل «عملاء بلا إعلانات» يظهر مباشرة بعد نهاية المقال، ليس بعد كل البطاقات.
5. حقل التعليق ظاهر مباشرة تحت «كن أول من يعلق».
6. أيقونات SVG (Lucide) فقط — ممنوع الإيموجي كأيقونات أقسام (🗓️ 👁 ⭐ حاليًا).
7. لا تمرير أفقي أبدًا (الوضع الحالي سليم — حافظ عليه).
8. **فيد الرئيسية: زر «عرض المزيد» كل ~10 مقالات — ممنوع الـ infinite scroll** حتى يبقى الفوتر على بُعد شاشة واحدة (NN/g). وكل روابط الفوتر منسوخة في البرغر.

## 4. Information Architecture v3 (إعادة الهيكلة)

### 4.1 التنقل الرئيسي — قبل وبعد

| قبل (v2) | بعد (v3) |
|---|---|
| الرئيسية · الرائجة · الشركاء · الصناعات · الوسوم | (شريط سفلي) الرئيسية · **العملاء** · **مدونتي ⭐** (زر أوسط بارز) · **لقطات** · بحث — الرائجة والصناعات في قائمة البرغر، وchips الصناعات أعلى الرئيسية وصفحة العملاء |

- صفحة `/clients` تبقى وتتطور: تبويب «العملاء» في الشريط السفلي، وأعلاها chips الصناعات للفلترة — مركز الاستكشاف الموحد (عملاء + قطاعات). دورها أيضًا إثبات اجتماعي وسيو.
- تدفق المستخدم: الصناعات ← صفحة الصناعة (عيادات الأسنان مثلًا) ← عملاء الصناعة + أحدث مقالاتها ← صفحة العميل ← المقال.
- صفحة الصناعة = **مزيج ذكي (معتمد)**: هيرو القطاع بأيقونته وعدّاداته ← أفضل 3 عملاء (بطاقات كبيرة بشارة التوثيق) ← أحدث 4 مقالات ← بقية العملاء ← بقية المقالات ← CTA انضمام. التبادل يخدم القارئ والمشتري معًا.
- الوسوم والفئات تبقى صفحات فرعية (من الفوتر وصفحة المقال)، وتُنظّف الفئات ثنائية اللغة («الرعاية الصحية Health Care» ← «الرعاية الصحية»).

### 4.2 مدونتي كـ Featured Publisher (جديد)

- **يُزال عميل «مدونتي» من شبكة الشركاء** ومن قائمة «الشركاء» الجانبية — لا يُعرض كعميل عادي.
- مكانه الجديد (**معتمد — الاثنين معًا**):
  - تبويب **«جديد مدونتي ⭐»** في التنقل الرئيسي يودي لصفحة محتوى المنصة.
  - بلوك «من مدونتي» Featured أعلى فيد الرئيسية (بطاقة أفقية مميزة بأحدث 3 مقالات للمنصة).
  - في صفحات الصناعات وشبكة الشركاء: لا يظهر إطلاقًا ضمن العملاء.
  - رابط دائم في الفوتر وفي «عن مدونتي».
- أي محتوى تكتبه المنصة نفسها يحمل وسم «من فريق مدونتي» بدل معاملة المنصة كعميل.

### 4.3 مخططات الصفحات (Blueprints)

**Home (mobile):** هيدر مضغوط ← chips صناعات قابلة للتمرير أفقيًا (جديد — التصفية مفقودة حاليًا على الموبايل) ← بلوك «من مدونتي» Featured ← فيد المقالات ← شريط الأثر الرقمي ← فوتر (بدون الفجوة البيضاء الحالية ~500px).

**Industry page:** هيرو القطاع ← عملاء القطاع (بطاقات بشعار + شارة توثيق + عدد المقالات) ← أحدث مقالات القطاع ← CTA «انضم كعميل».

**Client page:** هيرو (غلاف/شعار/اسم/مدينة بالعربية/شارة توثيق/إحصاءة جوجل) ← تبويبات (المقالات · التقييمات · الأسئلة · عن) ← المحتوى ← شريط سفلي واحد: «احجز الآن» (إملاء صحيح — حاليًا «الان») + واتساب + متابعة/حفظ. الرقم الضريبي خلف «التوثيق» وليس مكشوفًا.

**قاعدة CTA هدف العميل (معتمد):** كل مقال ينتهي بـ CTA تحويل خاص بالعميل حسب نوعه — عيادة: «احجز موعدك ↗»، متجر: «اطلب المنتج ↗» (رابط المنتج نفسه)، خدمات: «اطلب عرض سعر / زيارة الموقع ↗» — مع واتساب. CTA المنصة («عملاء بلا إعلانات») لا يظهر أبدًا فوق أو قبل CTA العميل — يوضع صغيرًا بعد المقالات ذات الصلة.

**Article page:** بريدكرمب ← H1 ← سطر ميتا واحد لا ينكسر ← بطاقة العميل الموثقة ← المتن ← أسئلة شائعة ← مصادر ← صندوق التحويل ← تعليقات (حقل ظاهر) ← عن الكاتب (بالعربية) ← 3 مقالات ذات صلة ← فوتر.

## 4.4 قسم «لقطات» — Reels (جديد)

> فيديوهات وصور قصيرة بأسلوب تيك توك — **كل لقطة تتبع عميلًا** (وربطها بمقال حالة اختيارية استثنائية).
> ينتجها العميل نفسه من الكونسول بمراجعة إدارية — المنصة لا تنتج ريلز لكل مقال (لا يتوسع أبدًا).
> CTA اللقطة يختاره العميل عند الرفع من أربعة: صفحتي (الافتراضي) / واتساب / احجز-اطلب / مقال محدد.

### التسمية والدخول
- الاسم المعتمد مبدئيًا: **«لقطات»** (بديل: «ريلز مدونتي»).
- نقاط الدخول: تبويب «لقطات» في التنقل + صف دوائر أفقي (Stories-style) أعلى الرئيسية تحت chips الصناعات بإطار إنديجو متدرج للجديد + قسم «لقطات العميل» في صفحة كل عميل.

### العارض (Viewer)
- شاشة كاملة 9:16، تمرير عمودي snap — لقطة واحدة في الشاشة.
- ثلاثة أنواع وسائط يرفعها العميل من الكونسول:
  1. **فيديو** ≤ 60 ثانية — تشغيل تلقائي مكتوم + زر صوت (Bunny Stream يحوّله HLS عموديًا 9:16).
  2. **صورة واحدة** — تُعرض 5–7 ثوانٍ بحركة زوم خفيفة (Ken Burns).
  3. **مجموعة صور (2–10)** — لقطة واحدة بتمرير أفقي داخلي بين الصور + نقاط (Photo Mode) — أسهل إنتاج للعميل: تصوير جوال بدون مونتاج.
- قيود الرفع في الكونسول: فيديو ≤ 200MB (يُضغط تلقائيًا)، صور ≤ 10MB للصورة، والقص لـ 9:16 داخل أداة الرفع.
- شريط تقدم رفيع أعلى الشاشة.
- طبقة المعلومات أسفل الشاشة: شعار العميل + الاسم + «موثّق ✓» ← وصف سطر واحد ← **زر CTA واحد** يحدده العميل: «زيارة صفحتي» (افتراضي) / واتساب / «احجز الآن-اطلب» / «اقرأ المقال» (فقط إن كان الريل عن مقال).
- عمود تفاعل جانبي: إعجاب، مشاركة، حفظ — أهداف 44px وعدّادات بأرقام مشرقية.

### الحوكمة والترتيب
- النشر عبر Console العميل بمراجعة إدارية (كما المقالات) — جودة المنصة تبرر جعل «لقطات» ميزة للباقات الأعلى (upsell).
- الترتيب بالتفاعل داخل كل صناعة، ومحتوى «مدونتي» الرسمي مثبت بشارة «الناشر الرسمي ⭐».
- محتوى مدونتي الرسمي لا يُحسب ضمن لقطات العملاء (نفس فلسفة Featured Publisher).

### القياس (GA4 من اليوم الأول)
- أحداث: `reel_view`، `reel_complete`، `reel_cta_click`، `reel_share`، `reel_like` — كلها بمعرّف العميل والصناعة.
- تظهر في لوحة Console للعميل («اللقطة جابت لك ٤٧ زيارة») — حجة البيع الأساسية.

### تقنيًا — Bunny.net (معتمد)
- الفيديو: **Bunny Stream** — رفع عبر API، تحويل تلقائي HLS/adaptive bitrate، صورة poster فورية (لا شاشة سوداء)، وWebP animated preview للدوائر.
- التوصيل: **Bunny CDN** بنقاط حضور الشرق الأوسط (جدة/الرياض حسب التوفر) لتقليل زمن بدء التشغيل للجمهور السعودي.
- الصور الحالية للموقع تبقى على Cloudinary كما هي — Bunny خاص بقسم اللقطات (ويمكن تقييم نقل الصور لاحقًا لتوحيد المزود).
- القسم lazy بالكامل: لا يؤثر على LCP للرئيسية، لا autoplay على شبكات ضعيفة (Save-Data)، والتحميل المسبق للقطة التالية فقط.

### 4.5 قاعدة الاشتراك — عند لحظة الحاجة (معتمد)

- لا زر «اشترك» دائم في الهيدر، ولا نافذة اشتراك في أول زيارة (عقوبة Google الرسمية للـ intrusive interstitials + أبحاث NN/g).
- طلب التسجيل يظهر فقط عند فعل يحتاج حسابًا: حفظ، متابعة، تعليق، أو المقال الثاني — bottom sheet «سجّل مجانًا» ← صفحة الدخول الموحدة (login + signup).
- «حسابي» في الشريط السفلي هو المدخل الدائم للحساب.

## 5. Components

- الأساس: shadcn/ui + Tailwind + Lucide (كما v2): Button, Card, Input, Badge, Avatar, Dialog, Accordion, DropdownMenu, Select, Textarea.
- أنماط مدونتي الخاصة:
  - **IndustryChip**: ارتفاع 40px، radius 20px، أيقونة قطاع + اسم، حالة مفعّلة بـ `--primary`.
  - **FeaturedModontyCard**: خلفية `--featured`، حد 1.5px indigo، شارة «الناشر الرسمي».
  - **BottomActionBar**: ارتفاع 64px، 3–4 أفعال كحد أقصى، labels ≥13px، safe-area padding.
  - **TrustBadge**: «موثّق من مدونتي» — SVG موحّد بثلاث مقاسات (16/20/24px).
  - **StatsStrip**: أرقام مشرقية، label ≥12px، بدون إيموجي.
- الروابط: underline للروابط النصية، `hover:opacity-80`، لوجيكال بروبرتيز (`ms-/me-/ps-/pe-`) دائمًا.

### 5.1 قواعد معتمدة إضافية

- **الأثر الرقمي يظهر فقط في سياقات البيع** (بطاقة «انضم كعميل»، صفحة العملاء، صفحة المزايا) — لا يُعرض كقسم مستقل للقارئ العادي؛ هو معيار مصداقية موجه للعميل المحتمل الدافع.
- **مقاس صور المقالات ثابت 16:9 في كل السياقات** (فيد، ديسكتوب، ذات صلة، بحث) — نفس أصل Cloudinary الحالي بأحجام srcset مختلفة فقط. ممنوع أي layout يتطلب قصًا جديدًا للصور القائمة.

## 6. Accessibility & Performance

- WCAG 2.1 AA: تباين 4.5:1، focus ring واضح، `alt` لكل صورة (يوجد حاليًا صور بلا alt)، H1 واحد لكل صفحة، تسلسل عناوين سليم.
- الحركة: transitions ≤ 300ms على transform/opacity فقط.
- ميزانية الأداء (موبايل + ديسكتوب — ملزمة):
  - LCP < 2.5s · CLS < 0.1 · INP < 200ms.
  - الصور: أصل 16:9 واحد لكل مقال، `f_auto,q_auto` + srcset (640/828/1080)، `loading="lazy" decoding="async"` لكل ما تحت الطية، وأبعاد محجوزة بـ `aspect-ratio`.
  - الخط: عائلة واحدة (Tajawal) بثلاثة أوزان كحد أقصى، `display=swap`، preconnect لـ fonts.gstatic.com وBunny CDN.
  - JS الواجهة العامة: بدون مكتبات UI ثقيلة — التفاعلات بـ CSS أولًا، وscroll handlers ممنوعة (sticky/IntersectionObserver فقط).
  - اللقطات lazy بالكامل ولا تدخل في حساب LCP للرئيسية.
