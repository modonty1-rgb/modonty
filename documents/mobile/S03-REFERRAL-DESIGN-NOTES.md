# S03 — تصور الإحالة

## نطاق صورة المراجعة

هذه الشاشة تصور UI كامل ببيانات عربية **تجريبية للتصميم فقط**. لا تمثل حقول API أو قاعدة بيانات جاهزة، ولا تدخل التطبيق قبل بناء العقد.

## ما تعرضه الصورة

| العنصر | بيانات التصميم |
|---|---|
| رقم العميل | `055 123 4567` |
| تأكيد المرشّح | شرح الخدمة وموافقة العميل على التواصل |
| الإجراء الأساسي | إرسال بيانات العميل |
| رحلة المكافأة | إرسال الرقم → تواصل مدونتي → اشتراك العميل وسداد الدفعة → شهر مجاني تلقائياً |
| سجل الإحالة | عيادات الروّاد — قيد التواصل |

## عقد الوظائف المطلوب بعد اعتماد UI

1. `ReferralLead` يملك رقم الجوال فقط، معرف المرشّح، تأكيد شرح الخدمة/الموافقة، والحالة وتواريخها.
2. تأكيد إرسال قبل الحفظ، ثم سجل إحالات يعرض حالة التواصل والاشتراك والسداد والاستحقاق.
3. يتحقق الخادم من دفع العميل الجديد ويربطه بالترشيح؛ عندها فقط يمنح الشهر تلقائياً.
4. الاستحقاق idempotent وله سجل تدقيق يمنع إضافة الشهر مرتين.
5. تأكيد المرشّح ليس بديلاً عن إبلاغ العميل المرشّح وأخذ موافقته مباشرة عند التواصل معه.

## حالات الشاشة الإلزامية

- تحميل: هيكل للعرض، الرابط، الخطوات والسجل.
- فارغ: لا توجد إحالات بعد مع إجراء المشاركة فقط.
- خطأ: تعذر تحميل برنامج الإحالة + إعادة محاولة.
- بلا شبكة: حالة مستقلة + إعادة محاولة عند الاتصال.
