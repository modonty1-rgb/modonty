# ترقيم شاشات Console Mobile

## القاعدة

الترقيم يبدأ بعد `S02` بحسب مسار العميل من أعلى الرئيسية إلى أسفلها، ثم أسطح التصفح التابعة له. وسم `Sxx` الأحمر في صور المراجعة مرجع لخالد وفريق التنفيذ فقط، ولا يدخل تطبيق الإنتاج.

| المعرّف | السطح | من أين يصل العميل؟ |
|---|---|---|
| S03 | تفاصيل الإحالة | Hook الإحالة في أعلى الرئيسية |
| S04 | تفاصيل الاشتراك | بطاقة الاشتراك |
| S05 | مقالات بانتظار القرار | صف مهام المقالات |
| S06 | بوابة مراجعة المقال | من S05؛ المرجع الجامع لحالة المقال والأسئلة والاستشهادات |
| S07-article | المقال | من S06؛ HTML المقال وقرار اعتماده أو طلب تعديله |
| S07-questions | أسئلة فريق مدونتي | من S06؛ أسئلة SEO المرتبطة بالمقال وقرار كل سؤال |
| S07-citations | استشهادات المقال | من S06؛ المصادر وقرار كل استشهاد |
| S08-audience | أسئلة القراء والتعليقات | صفا الأسئلة والتعليقات |
| S08-audience-reply | الرد على سؤال قارئ | من S08-audience |
| S09 | الفيديوهات | صف مهام الفيديوهات |
| S10 | رفع الفيديو | من S09 عند وجود هذا المسار |
| S11 | المقالات المنشورة | تبويب المقالات |
| S12 | التنبيهات | تبويب التنبيهات |
| S13 | الحساب | قائمة الحساب |
| S14 | الدعم | قائمة الحساب |
