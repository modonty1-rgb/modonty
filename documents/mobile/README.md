# قواعد تطبيقات الموبايل — المصدر الرئيسي

هذا المجلّد هو **المصدر الرئيسي والحاكم** لقواعد تطبيقي `console-mobile` و`modonty-mobile`.

| الطبقة | المرجع الحاكم | يحكم |
|---|---|---|
| الواجهة والتجربة | `UIUX-RULES.md` | اللمس · التباين · المسافات · الخطوط · المساحة الآمنة · الحالات · RTL · الماركة |
| الهندسة | `ENGINEERING-RULES.md` | القوائم · الحركة · التنقّل · الصور · البيانات · الشبكة · المستودع · الدليل |

تُقرأ القاعدتان كاملتين قبل أول سطر تنفيذ. وعند تعارض أي وثيقة محلية أو سابقة معهما، فهما الحاكمان.

## الترتيب الملزم للشاشة

```
نطاق الشاشة + بيانات عربية واقعية
   → صورة واحدة معتمدة من خالد
   → تنفيذ من tokens/components فقط
   → لقطة جهاز أندرويد فعلي ومقارنة بالصورة
   → تعديل ذاتي
   → عرض
```

لا تُعرض شاشة قبل استيفاء بوابة التسليم المذكورة في `UIUX-RULES.md`، ولا يُدّعى اكتمال التنفيذ بلا دليل وفق `ENGINEERING-RULES.md`.

## الوثائق المحلية

توثيق `console-mobile/documentation/` سياقي أو تاريخي. ملف `UI-RULES-console-mobile.md` مرجع مساعد فقط، ولا ينسخ أو يعلو القاعدتين هنا.
