# documents

كل ورقة في المستودع تسكن هنا. لا يوجد مجلّد `documents/` داخل أيّ تطبيق —
`modonty/documents/` نُقل إلى `documents/modonty/` في ١٤ أغسطس ٢٠٢٦، لأن ورقة تخصّ
تطبيقاً واحداً ما زالت ورقة، ومكان البحث عنها يجب أن يكون واحداً.

## أين تضع الورقة؟

**السؤال الوحيد:** هل تُقرأ هذه الورقة وأنت تشتغل على تطبيق واحد بعينه؟
نعم ← مجلّد ذلك التطبيق. لا ← الجذر.

```
documents/
  modonty/   الموقع العام وحده — codex · v3-handoff · reels · legal · seo · mockups · bridge
  admin/     لوحة الفريق وحدها — mockups
  console/   لوحة العميل وحدها — mockups
  archive/   ما لا نحتاجه الآن. لا يُحذف شيء، يُنقل هنا.
  …          الباقي مشترك بين التطبيقات
```

## المشترك

| المجلّد | ما فيه |
|---|---|
| `context/` | سجلّ الجلسات — مصدر الحقيقة بين الجلسات |
| `tasks/` | لوحة الشغل `TASK.html` وملاحظات التنفيذ |
| `contract/` | الاتفاقات وقواعد العمل |
| `guideline/` | `SYNTHESIS.md` و`GOLDEN-RULES.md` — المستخلص. مصادره الخام في الأرشيف. |
| `guides/` | أدلّة التشغيل |
| `design/` · `diagrams/` · `brand/` | نظام التصميم · مخطّطات القاعدة والتدفّقات · الهويّة والأيقونات |
| `content-plan/` · `content-team/` | خطط المحتوى وفريقه |
| `mockups/` | محاكاة واجهات لم يحسم تصنيفُها الآليّ تطبيقَها. ما يُعرف مالكه يسكن `<app>/mockups/`. |

مرجع أي عمل بصري يبدأ من `design/README.md`. لا تنتقل معاينة من `documents/design/assets/`
إلى كود التطبيق قبل موافقة خالد ثم أمر تنفيذ صريح منفصل.

## الأرشيف

`archive/` ليس سلّة مهملات — هو ما استُغني عنه اليوم ويُحتمل الرجوع إليه:

| | لماذا |
|---|---|
| `guideline-sources/` | المصادر الخام (١٧ ميغا، منها كتاب هويّة PDF بـ١٦). `SYNTHESIS.md` هو ما يُقرأ. |
| `gsc-csv-2026-08-03/` | تصدير خام ليوم واحد |
| `issues/` | أعطال محسومة، يونيو–يوليو |
| `audits/` | تدقيقات قديمة، بعد استخراج مهارة السيو منها |

## ما نُقل خارج `documents/`

ملفّان لم يكونا وثائق أصلاً:

- `audits/setSenior/seo-expert-files/` → `.claude/skills/seo-senior-expert/` (مهارة كاملة: `SKILL.md` + ١١ مرجعاً)
- `myskill/languageStyle.md` → `.claude/skills/language-style.md`
