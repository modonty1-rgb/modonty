# نظام التصميم — مستخرج من الـ Live DOM

**المصدر:** `linkedin.com/feed/` — قيم حقيقية مقروءة من `getComputedStyle` على الصفحة الحية، مو من تخمين أو من سكرين شوت.
**تاريخ الاستخراج:** 14 أغسطس 2026
**الـ Viewport وقت القياس:** 1117px عرض
**الهدف:** نظام عام قابل لإعادة الاستخدام في مشروعك — مو نسخة حرفية. كل الـ tokens أسميتها بأسماء محايدة (`--surface`, `--brand`) عشان تركّب عليها هويتك بدون ما تورّث أسماء المنصة.

---

## 0. الخلاصة السريعة (لو ما عندك وقت تقرأ الباقي)

النظام كله يقوم على **ستة قرارات** بس. لو طبّقتها صح، 90% من الشكل بيجيك:

| # | القرار | القيمة |
|---|--------|--------|
| 1 | خلفية الصفحة **مو بيضاء** — بيج دافي، والكروت بيضاء فوقها | `#F4F2EE` خلف `#FFFFFF` |
| 2 | **صفر ظلال**. الفصل بين الكرت والخلفية يجي من حلقة 1px | `box-shadow: 0 0 0 1px rgba(140,140,140,.2)` |
| 3 | النص **مو أسود** — أسود بشفافية على 3 مستويات | `rgba(0,0,0,.9 / .75 / .6)` |
| 4 | **وزنين خط بس**: 400 و 600. ما فيه 500 ولا 700 | `font-weight: 400 \| 600` |
| 5 | **نصف قطر مزدوج**: 8px للحاويات، 999px للأزرار والأفاتار | `--r-card: 8px` / `--r-pill: 999px` |
| 6 | كل زر تفاعلي عنده **هدف لمس 48px** يلف عنصر مرئي أصغر | `min-height: 48px` |

> ⚠️ **أهم شي في النظام كله**: النقطة رقم 2. الناس تحاول تقلّد هالشكل بـ `box-shadow: 0 2px 8px rgba(0,0,0,.1)` وتطلع النتيجة "رخيصة". السر إنه **ما فيه ظل إطلاقاً** — فيه حلقة رمادية بسمك 1px حول الكرت، وهذي تعطي حدّة ونظافة الظل ما يعطيها.

## 1. الأساسات (Foundations)

### 1.1 جذر الحجم — لماذا 10px

```css
html { font-size: 62.5%; }   /* = 10px */
```

هذي حيلة قديمة بس فعّالة: تخلي حساب الـ rem سهل ذهنياً — `1.4rem = 14px`، `2.4rem = 24px`. ما تحتاج تضرب في 16 وتقسم كل مرة.

**التفصيل الممل:** الموقع يحدّد `border-width: 0.125rem` وهذي تطلع `1.25px` في الـ computed style. هذا مو خطأ — هو نتيجة الحساب `0.125 × 10px`. في مشروعك **استخدم `1px` مباشرة**، أنظف بصرياً ولا يعطيك خط ضبابي عند بعض نسب البكسل.

### 1.2 عائلة الخط

```css
--font-sans:
  system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto,
  Ubuntu, Oxygen, Cantarell, "Fira Sans", "Droid Sans",
  "Helvetica Neue", Arial, sans-serif,
  "Apple Color Emoji", "Segoe UI Emoji", "Segoe UI Symbol";
```

خط النظام — صفر تحميل، صفر FOUT، وياخذ شكل الجهاز الأصلي.

**لمشروعك العربي:** ضيف خط عربي **قبل** `sans-serif` في نفس السلسلة:

```css
--font-sans: "IBM Plex Sans Arabic", system-ui, -apple-system,
             BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif;
```

المتصفح يختار العربي للحروف العربية والنظام للحروف اللاتينية والأرقام تلقائياً. **لا تسوي `:lang(ar)` selectors منفصلة** — تكسر النص المختلط (اسم شركة إنجليزي داخل جملة عربية).

## 2. الألوان — النظام الكامل

### 2.1 الأسطح (Surfaces)

| Token | القيمة | RGB | الاستخدام |
|-------|--------|-----|-----------|
| `--bg-page` | `#F4F2EE` | `244, 242, 238` | خلفية الصفحة الكاملة — بيج دافي، **ليس رمادي** |
| `--surface` | `#FFFFFF` | `255, 255, 255` | كل الكروت والـ nav bar |
| `--surface-warm` | `#FAF9F5` | `250, 249, 245` | أسطح ثانوية / مناطق مميزة |
| `--surface-info` | `#EDF3F8` | `237, 243, 248` | تنبيهات معلوماتية، bg أزرق فاتح |
| `--surface-notice` | `#FDF0DE` | `253, 240, 222` | تنبيهات / ترقية / برميوم |
| `--scrim` | `rgba(0,0,0,.6)` | — | طبقة معتمة خلف الـ modals |

**التفصيل الممل — ليش `#F4F2EE` وليس `#F5F5F5`؟**
لأن القيم الثلاث **متدرّجة نازل** (244 > 242 > 238) وليست متساوية. الفرق 6 نقاط بين الأحمر والأزرق يعطي دفء خفيف جداً — عينك ما تلاحظه كـ "بيج"، لكن تحسّه كـ "غير معقّم". الرمادي المحايد (`#F5F5F5`) يعطي إحساس شاشة إدارية باردة. هذا فرق يوم كامل من الـ polish.

**القاعدة:** أي لون خلفية محايد عندك، خلّ قناة الأزرق **أقل** من الأحمر بـ 4–8 نقاط.

### 2.2 النص — النظام الشفاف

```css
--text-1: rgba(0, 0, 0, 0.9);   /* أساسي — العناوين، أسماء الأشخاص، المحتوى */
--text-2: rgba(0, 0, 0, 0.75);  /* ثانوي — labels الأزرار، النص المساند */
--text-3: rgba(0, 0, 0, 0.6);   /* ثالثي — الطوابع الزمنية، الميتاداتا، nav غير نشط */
```

**ليش شفافية بدل ألوان صريحة؟** لأن نفس الـ token يشتغل فوق أي سطح — أبيض، بيج، أزرق فاتح — ويتكيّف تلقائياً. لو استخدمت `#333` صريح، فوق الخلفية البيج راح يبان غلط.

**عدد الاستخدامات الفعلي على الصفحة:**

```
rgba(0,0,0,.9)   → 985 عنصر   ← الافتراضي
rgba(0,0,0,.75)  → 234 عنصر
rgba(0,0,0,.6)   → 228 عنصر
#0A66C2          →  71 عنصر
```

النسبة تقريباً **4:1:1** — يعني الأغلبية الساحقة نص أساسي، والدرجات الأخف تُستخدم بحذر. لا تسوي الخطأ الشائع: تخلي نص الصفحة كله رمادي فاتح "عشان يبان ناعم". النتيجة صفحة بلا تسلسل هرمي.

**للوضع الداكن (Dark Mode):** اقلب النظام لـ `rgba(255,255,255,.9 / .75 / .6)` على خلفية `#1B1F23`. نفس البنية بالضبط.

### 2.3 العلامة والتفاعل (Brand & Interactive)

| Token | القيمة | الاستخدام |
|-------|--------|-----------|
| `--brand` | `#0A66C2` | الروابط، الأزرار الثانوية، الشعار، الأيقونات النشطة |
| `--brand-pressed` | `#004182` | hover + active — **أغمق بنسبة ~40%** |
| `--brand-wash` | `rgba(55, 143, 233, .1)` | خلفية الزر عند الـ hover |
| `--danger` | `#CB112D` | شارات الإشعارات، حالات الخطأ |
| `--premium` | `#C37D16` | روابط الترقية / المميز — ذهبي غامق |

**التفصيل الممل — `--brand-wash` مو نفس `--brand` بشفافية.**
لو أخذت `#0A66C2` وخليتها `rgba(10,102,194,.1)` بتطلع رمادية باهتة. القيمة الحقيقية `rgba(55,143,233,.1)` مبنية على **درجة أفتح وأكثر إشباعاً** (`#378FE9`)، عشان لما تنزل لـ 10% opacity تبقى تحس فيها أزرق. هذي تفصيلة يغفل عنها 90% من المقلّدين.

```css
/* ❌ غلط */
--brand-wash: rgba(10, 102, 194, .1);   /* يطلع رمادي */

/* ✅ صح */
--brand-wash: rgba(55, 143, 233, .1);   /* يطلع أزرق فعلاً */
```

### 2.4 الحدود والخطوط الفاصلة

| Token | القيمة | الاستخدام |
|-------|--------|-----------|
| `--hairline` | `rgba(140, 140, 140, .2)` | حلقة الكرت، فاصل الـ nav bar، فواصل القوائم |
| `--border-strong` | `rgba(0, 0, 0, .3)` | حدود حقول الإدخال |

`--hairline` رمادي بشفافية 20% — يعطي خط فاتح جداً بس مقروء، ويشتغل فوق الأبيض والبيج معاً.

### 2.5 ألوان الأيقونات المميّزة

الأيقونات في شريط إنشاء المنشور تستخدم ألواناً **مشبعة ومنخفضة الإضاءة** — مو ألوان براقة:

```css
--icon-media:    #44712E;   /* أخضر — فيديو */
--icon-image:    #B24020;   /* برتقالي محروق — صورة */
--icon-document: #0A66C2;   /* أزرق — مقال */
```

**القاعدة:** كل هذي الألوان عندها إضاءة (lightness) بين 30–40% في HSL. هذا يخليها تشتغل كأيقونات صغيرة 24px بدون ما تصير صارخة، وتحافظ على تباين كافي مع الخلفية البيضاء.

## 3. الطباعة (Typography)

### 3.1 السلّم الكامل

| Token | Size / Line-height | النسبة | Weight | الاستخدام الفعلي |
|-------|-------------------|--------|--------|-------------------|
| `--t-caption` | `12px / 15px` | 1.25 | 400 / 600 | الطوابع الزمنية، labels الـ nav، الميتاداتا |
| `--t-ui` | `14px / 17.5px` | 1.25 | 400 / 600 | **الافتراضي** — labels الأزرار، عناوين البطاقات الصغيرة |
| `--t-body` | `14px / 21px` | **1.5** | 400 | نص المحتوى الطويل — المنشورات، الفقرات |
| `--t-title-sm` | `16px / 20px` | 1.25 | 600 | عناوين البطاقات |
| `--t-title-md` | `20px / 25px` | 1.25 | 600 | عناوين الأقسام في الشريط الجانبي |
| `--t-title-lg` | `24px / 27px` | 1.125 | 600 | العنوان الرئيسي للصفحة |

**التفصيل الممل — النسبة المزدوجة 1.25 / 1.5**

هذي أذكى نقطة في النظام كله. لاحظ إن `14px` عنده **قيمتان** لارتفاع السطر:

- `14 / 17.5` (نسبة **1.25**) → للنصوص القصيرة في الواجهة. سطر واحد أو سطرين. ضيّق ومحكم.
- `14 / 21` (نسبة **1.5**) → للنصوص الطويلة. مريح للقراءة المتواصلة.

**نفس الحجم، سياقان مختلفان.** أغلب أنظمة التصميم تعطي `line-height` واحد لكل حجم وتخلص — وهذا يخلّي إما الواجهة فضفاضة أو المحتوى خانق. اعمل هذا الفصل في مشروعك:

```css
.ui-text    { font-size: 1.4rem; line-height: 1.25; }  /* labels, buttons, chips */
.body-text  { font-size: 1.4rem; line-height: 1.5;  }  /* paragraphs, posts */
```

**قاعدة النسبة 1.25:** كل العناوين تستخدم `1.25` بالضبط (12→15، 14→17.5، 16→20، 20→25). هذا يعني إن `line-height` قابل للحساب: `size × 1.25`. سهّل على نفسك:

```css
--lh-tight: 1.25;
--lh-relaxed: 1.5;
```

### 3.2 الأوزان — اثنان فقط

```
400  →  125 عنصر نصي
600  →  109 عنصر نصي
```

**ما فيه 500. ما فيه 700. ما فيه 300.**

هذا انضباط متعمّد. وزنان فقط يعني إن التمييز البصري لازم يجي من **الحجم واللون**، مو من الوزن. النتيجة صفحة أهدأ وأسهل مسحاً بالعين.

في مشروعك: احذف كل `font-weight: 500` و `700` من الكود. جرّب أسبوع بوزنين بس — بتلاحظ الفرق.

### 3.3 تركيبات جاهزة (الأكثر استخداماً فعلياً)

هذي التركيبات المقاسة فعلياً بترتيب التكرار — انسخها كما هي:

```css
/* ×42 — النص المساند (الأكثر شيوعاً على الإطلاق) */
font: 400 1.4rem/1.25 var(--font-sans); color: var(--text-3);

/* ×41 — الميتاداتا والطوابع الزمنية */
font: 400 1.2rem/1.25 var(--font-sans); color: var(--text-3);

/* ×33 — labels الأزرار */
font: 600 1.4rem/1.25 var(--font-sans); color: var(--text-2);

/* ×19 — الروابط */
font: 600 1.4rem/1.25 var(--font-sans); color: var(--brand);

/* ×18 — النص الأساسي في الواجهة */
font: 400 1.4rem/1.25 var(--font-sans); color: var(--text-1);

/* ×16 — عناوين البطاقات */
font: 600 1.6rem/1.25 var(--font-sans); color: var(--text-1);

/* ×9 — نص المحتوى الطويل */
font: 400 1.4rem/1.5  var(--font-sans); color: var(--text-1);
```

**`letter-spacing: normal` في كل مكان.** صفر تعديل على تباعد الحروف — لا للعناوين ولا للـ uppercase. خط النظام مضبوط أصلاً، وأي عبث بالـ tracking يكسر العربي تحديداً.

## 4. المسافات والقياسات

### 4.1 سلّم المسافات

```css
--space-1:  4px;   /* الفجوة بين أيقونة ونص */
--space-2:  8px;   /* الفجوة بين الكروت في العمود الجانبي */
--space-3: 12px;   /* padding رأسي داخل الكروت */
--space-4: 16px;   /* padding أفقي داخل الكروت — الأكثر استخداماً */
--space-5: 20px;   /* padding عناوين الأقسام */
--space-6: 24px;   /* فجوة الأعمدة في الشبكة */
--space-8: 32px;   /* إزاحات كبيرة */
```

**التفصيل الممل:** السلّم **ليس** مضاعفات 8 صافية. فيه `4, 12, 20` — يعني الأساس الفعلي هو **4px** مع تفضيل للقيم الزوجية من 8. لا تجبر نفسك على 8-point grid صارم؛ 4px base يعطيك مرونة أكثر بدون فوضى.

### 4.2 نصف القطر (Border Radius)

| Token | القيمة | عدد الاستخدامات | الاستخدام |
|-------|--------|------------------|-----------|
| `--r-pill` | `999px` | **51×** | الأزرار، الأفاتار، الحقول، الشارات |
| `--r-sm` | `4px` | **41×** | أزرار الأيقونات المربعة، شعارات الشركات، thumbnails |
| `--r-card` | `8px` | **16×** | كل الكروت والحاويات |
| `--r-button` | `24px` | 14× | الأزرار المستطيلة (بديل عملي للـ pill عند ارتفاع 32–48) |
| `--r-lg` | `12px` | 3× | حاويات كبيرة / modals |
| `--r-xl` | `32px` | 1× | نادر |

**النمط الحقيقي — قاعدة الحاوية مقابل التحكّم:**

```
حاوية (Container)  →  8px   ← الكروت، الأقسام، الـ modals
تحكّم (Control)    →  999px ← الأزرار، الحقول، الشارات، الأفاتار
مصغّرة (Thumbnail) →  4px   ← الصور المربعة، شعارات الكيانات
```

**لا تخلط.** أكبر خطأ شائع: تحط `border-radius: 8px` على الأزرار كمان. النتيجة إن الأزرار تختفي داخل الكرت وتفقد "قابلية النقر" البصرية. التباين بين الحاوية المربعة نسبياً والتحكّم البيضاوي تماماً هو اللي يخلّي الزر يقول "أنا زر".

**ملاحظة على `24px` مقابل `999px`:** الاثنان يعطيان نفس النتيجة البصرية على عنصر ارتفاعه ≤ 48px (لأن 24 = نصف 48). الفرق يبان بس لو العنصر أطول. استخدم `999px` وارتاح.

## 5. الارتفاع والظلال (Elevation)

### 5.1 القاعدة الذهبية: صفر ظلال

فحصت 1,588 عنصراً على الصفحة. عدد الظلال الحقيقية (blur > 0) المستخدمة في الواجهة الأساسية: **صفر**.

بدلها، النظام يستخدم **الحلقات (Rings)**:

```css
/* الكرت — حلقة خارجية 1px */
--ring-card:     0 0 0 1px rgba(140, 140, 140, .2);   /* ×7 على الصفحة */

/* الحالة النشطة / المحددة — حلقة داخلية */
--ring-active:   inset 0 0 0 1px rgba(0, 0, 0, .75);  /* ×8 */

/* الزر الثانوي — حلقة داخلية بلون العلامة */
--ring-brand:    inset 0 0 0 1px var(--brand);        /* ×4 */
--ring-brand-2:  inset 0 0 0 2px var(--brand-pressed);/* عند الـ hover */
```

**ليش حلقة بدل `border`؟** لأن `box-shadow` **لا تأخذ مساحة في الـ layout**. تقدر تغيّر سمكها من 1px لـ 2px عند الـ hover بدون ما ينتفض العنصر ولا يزحف الكونتنت حوله. لو استخدمت `border: 1px → 2px` بيقفز التصميم كل مرة.

```css
/* ❌ يسبب layout shift */
.btn        { border: 1px solid var(--brand); }
.btn:hover  { border: 2px solid var(--brand-pressed); }

/* ✅ صفر حركة */
.btn        { box-shadow: inset 0 0 0 1px var(--brand); }
.btn:hover  { box-shadow: inset 0 0 0 2px var(--brand-pressed); }
```

### 5.2 الاستثناء الوحيد — الطبقات العائمة

الظل الحقيقي محجوز حصرياً للعناصر اللي **تطفو فوق** الصفحة (toasts، مشغّل الفيديو العائم، الـ dropdowns):

```css
--shadow-float: 0 0 1px rgba(0, 0, 0, .45),
                0 4px 12px rgba(0, 0, 0, .6);
```

طبقتان: الأولى بـ blur=1 تعرّف الحافة بحدّة، والثانية بـ blur=12 وإزاحة 4px تعطي العمق. **لاحظ الشفافية العالية (.45 و .6)** — هذا ظل قوي جداً، لأنه يظهر بس فوق محتوى، فيحتاج يفصل بوضوح.

**القاعدة العملية لمشروعك:**

```
داخل تدفق الصفحة  →  ring (بدون ظل)
يطفو فوق الصفحة   →  shadow
```

## 6. الشبكة والتخطيط (Grid & Layout)

### 6.1 شبكة الـ 24 عمود

```css
.layout {
  display: grid;
  grid-template-columns: repeat(24, minmax(0, 1fr));
  column-gap: 24px;
  row-gap: 16px;
  max-width: 1128px;
  margin-inline: auto;
}
```

**القيم المقاسة فعلياً عند viewport = 1117px:**

| القيمة | المقاس |
|--------|--------|
| عرض الحاوية | `960px` |
| عدد المسارات | `24` |
| عرض المسار الواحد | `17.01px` |
| فجوة الأعمدة | `24px` |
| فجوة الصفوف | `16px` |

**التحقق الحسابي:** `(24 × 17.01) + (23 × 24) = 408.3 + 552 = 960.3` ✓

### 6.2 توزيع الأعمدة الثلاثة

| المنطقة | الأعمدة | العرض المقاس | الحساب |
|---------|---------|--------------|--------|
| الشريط الأيسر | `1 / 6` | **222px** | `6×17.01 + 5×24` |
| العمود الرئيسي | `7 / 16` | **386px** | `10×17.01 + 9×24` |
| الشريط الأيمن | `17 / -1` | **304px** | `8×17.01 + 7×24` |

```css
.rail-start { grid-column: 1 / 7;   }   /* 6 أعمدة  = 25% */
.rail-main  { grid-column: 7 / 17;  }   /* 10 أعمدة = 42% */
.rail-end   { grid-column: 17 / -1; }   /* 8 أعمدة  = 33% */
```

**ليش 24 عمود مو 12؟** لأن 24 تنقسم على 2, 3, 4, 6, 8, 12 — يعطيك مرونة `1/3` و `1/4` و `5/12` في نفس الشبكة. مع 12 عمود ما تقدر تسوي عمود بعرض 5/24 مثلاً. لو مشروعك بسيط 12 كافية؛ لو فيه لوحات تحكم معقّدة، خذ 24.

**للعربي (RTL):** استخدم `grid-column` مع `direction: rtl` على الحاوية — الشبكة تنقلب تلقائياً وما تحتاج تعيد تعريف أي شي. سمّ أعمدتك `rail-start` / `rail-end` **مو** `rail-left` / `rail-right`، عشان الأسماء تبقى صحيحة في الاتجاهين.

### 6.3 الفجوات الرأسية بين الكروت

| السياق | الفجوة |
|--------|--------|
| كروت الشريط الجانبي | `8px` |
| كروت التغذية (feed) | `4px` (داخل flex column) |
| بين الأقسام الكبرى | `24px` |

## 7. شريط التنقّل العلوي (Nav Bar) — التفصيل الكامل

### 7.1 الحاوية

```css
.navbar {
  height: 52px;                                  /* ثابت */
  background: var(--surface);                    /* #FFFFFF */
  border-bottom: 1px solid var(--hairline);      /* rgba(140,140,140,.2) */
  box-shadow: none;                              /* ← لا ظل إطلاقاً */
  position: static;                              /* غير مثبّت في هذا الإصدار */
}

.navbar__inner {
  display: flex;
  align-items: center;
  height: 100%;
  padding-inline: 16px;
}
```

**ثلاث ملاحظات مهمة:**

1. **`52px` وليس 56 أو 64.** ارتفاع محسوب: أيقونة 24px + label 12px/15px + هامش رأسي = يملأ 52 بالضبط. الشريط النحيف يترك مساحة أكبر للمحتوى.
2. **`border-bottom` وليس `box-shadow`.** خط حاد نظيف بدل تدرّج ضبابي. هذا يتماشى مع فلسفة "صفر ظلال".
3. **`position: static`.** الشريط يتمرّر مع الصفحة. لو بغيت تثبته: `position: sticky; top: 0; z-index: 100;` — بس لا تضيف ظل عند التمرير، خلّ الـ hairline يشتغل.

### 7.2 الشعار

```css
.navbar__logo {
  width: 34px;
  height: 34px;
  margin-inline-start: 16px;
  color: var(--brand);
}
```

SVG بلون العلامة، 34×34 — ما هو مربّع كامل الارتفاع، فيه هواء 9px فوق وتحت داخل الـ 52px.

### 7.3 حقل البحث

```css
.navbar__search {
  width: 280px;
  height: 34px;
  margin: 0 24px 0 8px;

  border: 1px solid var(--border-strong);   /* rgba(0,0,0,.3) */
  border-radius: var(--r-pill);             /* 999px */
  background: transparent;

  padding: 12px 16px 12px 40px;             /* ← 40px يسار لمكان الأيقونة */
  font: 400 1.4rem/1.25 var(--font-sans);
  color: var(--text-1);
}
.navbar__search::placeholder { color: var(--text-3); }
```

**التفصيل الممل:**

- **الخلفية شفافة، مو رمادية.** أغلب المواقع تسوي `background: #EEF3F8`. هنا الحقل شفاف والحد هو اللي يعرّفه. أنظف بكثير على شريط أبيض.
- **الحد `rgba(0,0,0,.3)` وليس `--hairline`.** الحقول تحتاج حد **أقوى** من فواصل الكروت لأنها تدعو لتفاعل. `.3` مقابل `.2` — فرق بسيط بس مقصود.
- **`padding-left: 40px`** يترك مساحة لأيقونة البحث 16px مع مسافات جانبية. الأيقونة موضوعة `position: absolute` داخل wrapper.
- **`padding` الرأسي 12px مع ارتفاع 34px** — يبدو متناقضاً (12+12+نص = أكثر من 34)، بس مع `box-sizing: border-box` النص يتمركز والـ padding يشتغل كحد أدنى.

**للعربي:** استخدم `padding-inline-start: 40px` بدل `padding-left` — تنقلب تلقائياً في RTL.

### 7.4 عناصر التنقّل

```css
.nav-item {
  min-width: 80px;
  height: 52px;

  display: flex;
  flex-direction: column;      /* أيقونة فوق، نص تحت */
  align-items: center;
  justify-content: center;

  position: relative;          /* للمؤشّر ::after */
  color: var(--text-3);        /* rgba(0,0,0,.6) — الحالة الافتراضية */
  cursor: pointer;
}

.nav-item__icon  { width: 24px; height: 24px; fill: currentColor; }
.nav-item__label { font: 400 1.2rem/1.25 var(--font-sans); color: currentColor; }
```

**`currentColor` هي المفتاح.** الأيقونة والنص كلاهما يرث من الأب — يعني تغيّر لون واحد وقت الـ hover ويتحرك الاثنان معاً. صفر تكرار.

### 7.5 الحالات (States) — مقاسة فعلياً بمحاكاة الماوس

| الحالة | لون النص | لون الأيقونة | المؤشّر السفلي |
|--------|----------|--------------|-----------------|
| افتراضي | `rgba(0,0,0,.6)` | `rgba(0,0,0,.6)` | شفاف |
| **Hover** | `rgba(0,0,0,.9)` | `rgba(0,0,0,.9)` | شفاف |
| **نشط (Active)** | `rgba(0,0,0,.9)` | `rgba(0,0,0,.9)` | **`rgba(0,0,0,.9)`** |

```css
.nav-item:hover        { color: var(--text-1); }
.nav-item[aria-current] { color: var(--text-1); }

/* المؤشّر — موجود دايماً، يتغيّر لونه فقط */
.nav-item::after {
  content: "";
  position: absolute;
  bottom: 0;
  left: 0;
  width: 100%;
  height: 2px;
  background: transparent;
}
.nav-item[aria-current]::after { background: var(--text-1); }
```

**التفصيل الممل — ثلاث نقاط ذكية هنا:**

1. **الـ hover ما يضيف خلفية.** ما فيه `background: #f3f2ef`. التغيير الوحيد هو الغمقان من `.6` لـ `.9`. هذا يخلّي الشريط هادي جداً عند تحريك الماوس — ما فيه مستطيلات رمادية تنطّ.

2. **المؤشّر السفلي موجود دائماً بلون شفاف.** ما ينشأ عند التنشيط — يتلوّن فقط. هذا يمنع أي `layout shift` ويسمح بـ transition سلس للون.

3. **المؤشّر بعرض 100% من العنصر (80px)** — مو بعرض النص. خط عريض واضح.

**عرض 80px ثابت لكل عنصر:** يعطي إيقاع منتظم في الشريط بغض النظر عن طول الكلمة ("Jobs" مقابل "Notifications"). النص الطويل يتقلّص بـ `text-overflow: ellipsis`.

### 7.6 شارات الإشعارات (Badges)

```css
.badge {
  position: absolute;
  top: -2px;
  inset-inline-start: 24px;     /* أعلى يمين الأيقونة */

  min-width: 16px;
  height: 16px;
  padding: 0 4px;               /* يتمدّد للأرقام ذات خانتين */
  border-radius: var(--r-pill);

  background: var(--danger);    /* #CB112D */
  color: #FFFFFF;
  font: 600 1.2rem/15px var(--font-sans);
  text-align: center;
}
```

**التفصيل الممل:**

- **`min-width: 16px` + `padding: 0 4px`** = الرقم "2" يعطي دائرة 16×16، والرقم "25" يعطي كبسولة 23×16. القياس الحقيقي من الصفحة: `2` → 16px، `25` → 23px. ✓
- **`top: -2px`** — الشارة تخرج قليلاً فوق حدود الأيقونة. الخروج المتعمّد يخليها تبان كطبقة منفصلة.
- **`#CB112D` وليس `#FF0000`.** أحمر مطفي بلمسة قرمزية — يشد الانتباه بدون ما يصرخ.
- **الوزن 600** ضروري: الرقم بحجم 12px يحتاج ثقل عشان يقرأ فوق خلفية حمراء.

### 7.7 روابط مميّزة (Premium / CTA)

```css
.nav-premium {
  color: var(--premium);        /* #C37D16 */
  text-decoration: underline;
  font: 600 1.2rem/1.25 var(--font-sans);
}
```

اللون الذهبي + التسطير = الرابط الوحيد المسطّر في الشريط كله. الندرة هي مصدر بروزه.

## 8. الكرت (Card) — النمط الأساسي

### 8.1 التعريف الأساسي

```css
.card {
  background: var(--surface);              /* #FFFFFF */
  border-radius: var(--r-card);            /* 8px */
  border: none;                            /* ← لا حدود */
  box-shadow: var(--ring-card);            /* 0 0 0 1px rgba(140,140,140,.2) */
  overflow: hidden;                        /* ← مهم جداً */
  padding: 0;                              /* الحشو على المحتوى الداخلي */
}
```

**`overflow: hidden` ليست تفصيلة ثانوية.** بدونها، أي صورة غلاف أو وسائط داخل الكرت راح تطلع زواياها المربعة خارج الحواف المدوّرة. هذي أشيع علة بصرية في تقليد هالنمط.

**`padding: 0` على الكرت نفسه** — الحشو يُطبّق على الأقسام الداخلية. هذا يسمح لعناصر مثل صور الغلاف والوسائط بالوصول لحافة الكرت (full-bleed) بينما النص يبقى محشوّاً.

### 8.2 أنماط الحشو الداخلي (مقاسة من ثلاثة كروت مختلفة)

| نوع الكرت | القيمة | الملاحظة |
|-----------|--------|----------|
| كرت وسائط / ملف شخصي | `0` | الغلاف يلمس الحواف |
| كرت إدخال (composer) | `12px 16px 4px` | أسفل أقل — لأن الأزرار تحته عندها هامش خاص |
| كرت قائمة | `8px 0` | رأسي فقط؛ العناصر الداخلية تأخذ الحشو الأفقي |
| عنوان القسم داخل كرت قائمة | `8px 20px` | 20px أفقي — أوسع من 16 |

**التفصيل الممل — لاحظ الحشو غير المتماثل `12px 16px 4px`:**
أعلى 12، جانبي 16، أسفل 4. الأسفل صغير جداً لأن العنصر التالي (صف الأزرار) عنده `min-height: 48px` مع حشو داخلي خاص فيه. لو خليت الأسفل 16 كمان، بيصير المجموع 16+12 = 28px فراغ ميت. **الحشو غير المتماثل هو علامة تصميم ناضج** — يعني أحد قاس فعلاً بدل ما نسخ قيمة واحدة لكل الجهات.

### 8.3 بنية كرت الملف الشخصي (المقاسة)

```
┌────────────────────────────────────┐  ← الكرت: 222×242, r=8, ring
│ ▓▓▓▓▓ صورة الغلاف ▓▓▓▓▓  56px      │  ← full-bleed للحواف
│   ⬤ الأفاتار 80px                   │  ← margin: 32px 0 0 16px (متداخل)
│      حلقة بيضاء 1px                 │  ← border: 1px solid #FFF
├────────────────────────────────────┤
│  الاسم        16px/20px  600        │  ← padding: 0 16px 16px
│  الوصف        12px/15px  400 .6     │
│  الموقع       12px/15px  400 .6     │
│  ─────────────────────────           │
│  ▣ اسم الشركة  24px أيقونة, gap 8   │
└────────────────────────────────────┘
```

**تقنية الأفاتار المتداخل:**

```css
.card__cover  { height: 56px; }
.card__avatar {
  width: 80px;
  height: 80px;
  margin: 32px 0 0 16px;        /* 32 < 56 → يتداخل مع الغلاف */
  border-radius: var(--r-pill);
  border: 1px solid #FFFFFF;    /* ← الحلقة البيضاء تفصله عن الغلاف */
}
```

الحلقة البيضاء 1px حول الأفاتار **ضرورية** — بدونها يذوب الأفاتار في صورة الغلاف لو كانت ألوانها قريبة. تفصيلة صغيرة، فرق كبير.

### 8.4 كرت القائمة (الشريط الجانبي)

```css
.card--list        { padding: 8px 0; }
.card--list__title { padding: 8px 20px; font: 600 2rem/25px var(--font-sans); }
.card--list__item  { padding: 8px 20px; min-height: 48px; }
```

الحشو الأفقي `20px` (مو 16) لأن هذا كرت ضيّق 304px ويحتاج هواء جانبي أكثر نسبياً.

## 9. الأزرار (Buttons) — النظام الكامل

### 9.1 الزر الثانوي (Pill) — النمط الأساسي

```css
.btn {
  display: flex;
  align-items: center;
  justify-content: center;
  gap: 4px;                                  /* بين الأيقونة والنص */

  height: 32px;
  padding: 4px 12px;
  border-radius: 24px;                       /* = pill عند 32px ارتفاع */

  background: transparent;
  color: var(--brand);
  border: none;
  box-shadow: inset 0 0 0 1px var(--brand);  /* ← الحلقة بدل الحد */

  font: 600 1.4rem/1.25 var(--font-sans);
  cursor: pointer;

  transition: box-shadow .216s cubic-bezier(.34, 0, .21, 1);
}

.btn:hover {
  background: var(--brand-wash);                      /* rgba(55,143,233,.1) */
  color: var(--brand-pressed);                        /* #004182 */
  box-shadow: inset 0 0 0 2px var(--brand-pressed);   /* 1px → 2px */
}
```

**القيم مقاسة فعلياً بمحاكاة hover حقيقي على الصفحة:**

```
قبل:  bg=transparent            color=#0A66C2  ring=1px inset #0A66C2
بعد:  bg=rgba(55,143,233,.1)    color=#004182  ring=2px inset #004182
```

**ثلاثة تغييرات متزامنة عند الـ hover:** الخلفية، اللون، وسمك الحلقة. أغلب الأنظمة تغيّر واحداً بس. التغيير الثلاثي يعطي إحساس "الزر استجاب بجد".

### 9.2 هدف اللمس 48px — أهم نمط وصولية في النظام

هذا اكتشاف مهم من الاستخراج: **العنصر `<button>` الفعلي ارتفاعه 48px، والشكل المرئي داخله 32px بس.**

```css
/* الغلاف — هدف اللمس */
.btn-hit {
  display: flex;
  align-items: center;
  min-height: 48px;        /* ← WCAG 2.5.5 target size */
  background: transparent;
  border: none;
  padding: 0;
  cursor: pointer;
}

/* الداخل — الشكل المرئي */
.btn-hit > .btn-visual {
  height: 32px;
  border-radius: 24px;
  padding: 4px 12px;
  /* ... باقي التنسيق ... */
}
```

**ليش هذا مهم؟** زر بارتفاع 32px يفشل معيار WCAG لحجم الهدف (44×44 كحد أدنى). بدل ما تكبّر الزر بصرياً وتخرب الكثافة البصرية، تلفّه في غلاف 48px شفاف. المستخدم يشوف زر أنيق صغير، وإصبعه يصيب منطقة كبيرة.

**طبّق هذا على كل عنصر تفاعلي عندك.** القياسات الفعلية أثبتت إن نفس النمط مستخدم على:
- أزرار المتابعة (`48px` غلاف / `32px` مرئي)
- أزرار التفاعل الاجتماعي (`48px`)
- أزرار الأيقونات (`48px` / `32px`)
- عناصر التنقّل (`52px` — الشريط نفسه هو الهدف)

### 9.3 زر الأيقونة (Icon Button)

```css
.btn-icon {
  width: 32px;
  height: 32px;
  padding: 8px;                        /* → أيقونة 16px في المنتصف */
  border-radius: var(--r-pill);        /* 999px — دائرة كاملة */
  background: transparent;
  color: var(--text-2);                /* rgba(0,0,0,.75) */
}
.btn-icon:hover { background: rgba(0, 0, 0, .08); }
```

### 9.4 زر إجراء الإنشاء (Composer Action)

```css
.btn-compose {
  display: flex;
  align-items: center;
  gap: 4px;
  padding: 12px 8px;
  border-radius: var(--r-sm);          /* 4px ← مو pill! */
  background: transparent;

.btn-compose__icon  { width: 24px; height: 24px; }   /* بلون مميّز */
.btn-compose__label { font: 600 1.6rem/20px var(--font-sans); color: var(--text-2); }
```

**لاحظ `4px` بدل `999px`** — أزرار الإنشاء تستخدم نصف قطر صغير لأنها متجاورة في صف؛ الشكل البيضاوي كان بيخليها تبان كأقراص منفصلة. الشكل شبه المستطيل يجمعها كمجموعة واحدة.

### 9.5 صف التفاعل الاجتماعي

```css
.social-bar        { display: flex; }
.social-bar__btn   {
  flex: 1;
  min-height: 48px;

.social-bar__icon  { width: 16px; height: 16px; }         /* ← 16 مو 24 */
```

القياس الفعلي: كل زر `77×48`، الأيقونة `16px`. الأيقونة أصغر من 24 المعتادة لأن الزر يجمع أيقونة + نص أفقياً في مساحة ضيقة.

### 9.6 حقل الإدخال المحفّز (Input Trigger)

الحقل اللي في كرت إنشاء المنشور — يبدو كحقل نص لكنه زر يفتح نافذة:

## 10. الأفاتار والصور

### 10.1 سلّم المقاسات (مقاس فعلياً)

| المقاس | نصف القطر | السياق |
|--------|-----------|--------|
| `96px` | `999px` | الملف الشخصي الكبير |
| `80px` | `999px` | كرت الملف الشخصي في الشريط الجانبي |
| `48px` | `999px` | صف الإنشاء، قوائم الاقتراحات |
| `40px` | `4px` | رأس المنشور (كيان/شركة) |
| `32px` | `4px` | العناصر المضغوطة |
| `24px` | `4px` / `0` | inline، شعارات صغيرة |

### 10.2 القاعدة الحاسمة: الشكل يحمل المعنى

```css
.avatar--person { border-radius: var(--r-pill); }   /* 999px — دائرة */
.avatar--entity { border-radius: var(--r-sm);   }   /* 4px — مربّع مدوّر */
```

**هذي ليست تفصيلة جمالية — هي معلومة.**

- **دائرة = شخص** (إنسان)
- **مربّع مدوّر = كيان** (شركة، مجموعة، مؤسسة، وظيفة)

المستخدم يميّز بين "منشور من شخص" و"منشور من صفحة شركة" **قبل ما يقرأ الاسم**، من الشكل بس. هذا اختصار إدراكي قوي جداً وبتكلفة صفر.

طبّقه في مشروعك بصرامة. لا تخلط أبداً.

## 11. الحركة (Motion)

```css
--ease:     cubic-bezier(.34, 0, .21, 1);
--duration: .216s;
```

**التفصيل الممل — لماذا `.216s` وليس `.2s`؟**
المنحنى `cubic-bezier(.34, 0, .21, 1)` هو منحنى تباطؤ حاد (نقطة النهاية `.21, 1` تعني إن الحركة تصل لـ 100% بسرعة ثم تستقر). مع هذا المنحنى، المدة الفعّالة المحسوسة أقصر من الرقم المكتوب. الـ 216ms مضبوطة لتعطي إحساس ~180ms.

**الأهم:** الـ transition مطبّق على **`box-shadow` فقط** — مو `all`:

```css
/* ✅ من الصفحة الحقيقية */
transition: box-shadow .216s cubic-bezier(.34, 0, .21, 1);

/* ❌ لا تسوي هذا */
transition: all .216s ease;
```

`transition: all` يحرّك خصائص ما تتوقعها (`width`, `height`, `color` وقت تغيير الثيم) ويكلّف أداءً. حدّد الخاصية دائماً.

## 13. قائمة تحقّق للتطبيق

انسخها كـ checklist وامشِ عليها بند بند:

**الأساسات**
- [ ] `html { font-size: 62.5% }` وكل المقاسات بـ `rem`
- [ ] خلفية الصفحة `#F4F2EE` — **ليست بيضاء وليست رمادية محايدة**
- [ ] خط عربي في مقدمة سلسلة خط النظام

**اللون**
- [ ] نص بثلاث درجات شفافية (`.9 / .75 / .6`) — لا ألوان صريحة
- [ ] `--brand-wash` مبني على درجة أفتح مشبعة، مو من لون العلامة مباشرة
- [ ] لون واحد للخطر، ولون واحد للمميّز، وخلاص

**الطباعة**
- [ ] وزنان فقط: 400 و 600 — احذف كل 500 و 700
- [ ] نسبتان لارتفاع السطر: `1.25` للواجهة، `1.5` للمحتوى
- [ ] `letter-spacing: normal` في كل مكان

**الشكل**
- [ ] `8px` للحاويات، `999px` للتحكّمات، `4px` للمصغّرات — **لا خلط**
- [ ] أفاتار الأشخاص دائري، وأفاتار الكيانات مربّع مدوّر
- [ ] `overflow: hidden` على كل كرت فيه وسائط

**الارتفاع**
- [ ] صفر `box-shadow` داخل تدفق الصفحة — استخدم `ring` فقط
- [ ] الظل محجوز للطبقات العائمة فقط
- [ ] حالات الـ hover تغيّر سمك الحلقة، **لا** سمك الحد (منعاً للـ layout shift)

**التخطيط**
- [ ] شبكة 24 عمود، فجوة `24px` أفقي / `16px` رأسي
- [ ] حاوية `1128px` بحد أقصى
- [ ] أسماء الأعمدة `start` / `end` مو `left` / `right` (لدعم RTL)

**التفاعل والوصولية**
- [ ] كل عنصر تفاعلي عنده هدف لمس `48px` يلف الشكل المرئي
- [ ] `transition` على خاصية محدّدة، **ليس** `all`
- [ ] `currentColor` للأيقونات داخل العناصر التفاعلية
- [ ] المؤشّرات النشطة موجودة دائماً وتتغيّر بالـ `background` فقط

## 14. الأخطاء الخمسة اللي تكسر النظام

هذي أشيع الأخطاء عند تطبيق هالنمط. تجنّبها وأنت مرتاح:

| # | الخطأ | الأثر | الصحيح |
|---|-------|-------|--------|
| 1 | `box-shadow: 0 2px 8px rgba(0,0,0,.1)` على الكروت | الشكل يصير "قالب مجاني" | `box-shadow: 0 0 0 1px rgba(140,140,140,.2)` |
| 2 | خلفية الصفحة `#FFFFFF` أو `#F5F5F5` | الكروت تختفي / الجو بارد | `#F4F2EE` |
| 3 | `border-radius: 8px` على الأزرار | الأزرار تذوب في الكرت | `999px` للأزرار |
| 4 | `font-weight: 500` أو `700` | فوضى بصرية، فقدان الانضباط | `400` و `600` فقط |
| 5 | `border: 1px → 2px` عند الـ hover | ارتجاف التخطيط | `box-shadow: inset` بدل `border` |

## 15. مصدر البيانات ومنهجية التحقّق

كل القيم في هذا المستند **مقروءة برمجياً** من الصفحة الحية عبر `getComputedStyle`، وليست تقديرية:

| المقاس | الطريقة | النتيجة |
|--------|---------|---------|
| العناصر المفحوصة | مسح كامل للـ DOM | **1,588** عنصراً مرئياً |
| توزيع نصف القطر | إحصاء تكراري | `999px` ×51, `4px` ×41, `8px` ×16, `24px` ×14 |
| توزيع ألوان النص | إحصاء تكراري | `.9` ×985, `.75` ×234, `.6` ×228, brand ×71 |
| الظلال | إحصاء تكراري | 3 حلقات فقط + ظل عائم واحد |
| الشبكة | قراءة `gridTemplateColumns` | 24 مساراً × 17.01px + فجوة 24px = 960px ✓ |
| حالات الـ hover | محاكاة ماوس حقيقي ثم قراءة الأنماط | مؤكّدة على الأزرار وعناصر التنقّل |
| المقاسات | `getBoundingClientRect()` | مؤكّدة بحساب رياضي عكسي |

**تنبيه مهم:** القيم المرصودة `1.25px` للحدود و`1.99px` للمؤشّرات هي ناتج `0.125rem` و `0.2rem` على جذر 10px. في مشروعك استخدم `1px` و `2px` مباشرة — أنظف بصرياً وأقل عرضة لضبابية الحواف عند نسب البكسل غير الصحيحة.

**ملاحظة قانونية:** هذا توثيق لأنماط تصميم عامة (شبكة، سلّم طباعي، نظام مسافات، حالات تفاعل) قابلة لإعادة الاستخدام. **لا تنسخ** لون العلامة `#0A66C2` ولا الشعار ولا الأيقونات الخاصة — استبدل `--brand` بلون هويتك، والباقي بنية معمارية محايدة.
