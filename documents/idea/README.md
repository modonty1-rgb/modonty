# documents/idea — الأفكار قبل التنفيذ

قاعدة خالد (١٧ أغسطس ٢٠٢٦): **كل فكرة جديدة = ملف HTML واحد** نتناقش فيه ونطرحها،
وبعد اعتمادها نبدأ التنفيذ (وتنتقل بنودها إلى `documents/tasks/TASK.html`).

## القواعد

- **ملف لكل فكرة**، اسمه واضح باسم الفكرة بالعربي: `فكرة-الثقة-والتقييمات.html`.
- **ملف واحد فقط لكل فكرة** — الشاشات والموكب والنموذج كلها أقسام داخله (خالد: «ما أبغى أتشتّت في كثرة ملفات»).
- الملف يبدأ بمقدّمة تشرح الفكرة كاملة بحيث تُقرأ وحدها بعد شهور، ثم القرارات المطلوبة.
- التنفيذ لا يبدأ إلا بعد «اعتماد» صريح من خالد على الفكرة.

## أين الأفكار الآن؟

**٢٢ أغسطس ٢٠٢٦ — المجلّد فاضٍ.** كل ملفّات الأفكار نُقل محتواها بنوداً على
`documents/tasks/TASK.html` ثم حُذفت، بأمر خالد: «ملف تاسك واحد، ما أبغى أتوه».

| الفكرة | صارت بنداً |
|---|---|
| صفحة الشريك الجديدة + موكبها | `PARTNERPAGE` |
| بانِي موقع الشريك | `PARTNERSITE` |
| نظام الثقة والتقييمات | `PREV` |
| عجلة الحظ واكتشف الفروقات | `WHEEL` |
| دراسة صفحة المقال + حصيلة الجوّال | `I18NSHARED` |
| مودو — عشرة قرارات | `modonty/app/(site)/modo-chat/documentation/modo-decisions.html` |

**الوثائق المرجعية الباقية** (نظام التصميم · دليل بوابة العملاء · قواعد الكتّاب ·
الشروط · الخصوصية · عقد الاشتراك) صارت ملفاً واحداً: `documents/HTML/وثائق-مدونتي.html`.

> **قرار ينتظر خالد:** الفكرة الجديدة تُكتب هنا في `documents/idea/` كما كانت القاعدة،
> ولّا تُكتب بنداً مباشرة على اللوحة؟ إن كان الثاني، يُحذف هذا المجلّد وقاعدته معه.
