تفاعلات الريل — تيك توك بلا ديسلايك (🔒 قفله خالد 2026-07-06 «do without dislike»)

  • الشريط الجانبي: إعجاب 👍 (أيقونة الإبهام الموحدة بالمنصة) · تعليقات 💬 · حفظ 🔖 · مشاركة ↗️ — بعداداتها. بلا ديسلايك (نمط تيك توك).
  • السكيما: جداول اللايك (يدعم المجهول) والحفظ (يتطلب حساباً) + عدادات مخزنة — نفس نمط المقالات حرفياً. مدفوعة لقاعدة التطوير.
  • منفذ ومختبر حياً: الشريط بالفيد يسار البطاقة (مقابل النص العربي) · تفاؤلي · «سجّل الدخول أولاً» للزائر · المشاركة عبر مشاركة النظام.
  • 🔒 تعديل مقفل (خالد 2026-07-06 «do»): التعليقات مؤجلة للإصدار القادم — زر التعليقات انشال نهائياً من الشريط (زر ميت يحبط المستخدم)، والجداول باقية جاهزة بالقاعدة. هذا يعدّل قرار الريلز الأم رقم ٧ («تعليقات من اليوم الأول») — يُزامَن في الملف الأم مع الخطة التفصيلية.

٣ · خطة التنفيذ — كل البنود مقفلة، الطريق مفتوح (لا تأجيل — خالد 2026-07-07)

  1. ✅ دفع السكيما — تم (قاعدة التطوير، بعد فحص الرابط).
  2. ✅ فيد /reels تجريبي حي — سناب + تفاعلات (إعجاب/حفظ/مشاركة، بلا ديسلايك، التعليقات للإصدار القادم).
  3. ✅ إكمال الفيد (2026-07-07): غامر (طبقة كاملة فوق هيدر الموقع + زر خروج) + لانهائي بالدفعات (٦ لكل دفعة، مؤشر + مراقب مدمج، صفر مكتبات — مختبر: ٦←١٢←١٤ ويتوقف بالنهاية) + تنظيف عرض مدمج للريلز البعيدة. باقي للإنتاج: تنويع الشركاء بالترتيب (مع الحجم الحقيقي).
  4. مسار الرفع الجديد بالكونسول → منطقة الريلز + الصفّان (معرض فوري + ريل معلق) + الشيك بوكس بافتراضي مفعّل (البند أ) + عنوان/وصف تلقائي (البند د).
  5. شاشة اعتماد الريلز بالأدمن — قائمة المعلق ← اعتماد/رفض + تحرير العنوان والوصف قبل النشر.
  6. ترحيل صور المعرض القديمة من كلاودنري (من واجهة الأدمن) + تجديد JSON-LD + تنظيف كلاودنري عبر صيانة الأورفنز (إنتاج فقط).
  7. مرحلة الفيديو — الرفع لمكتبة الستريم الجاهزة (MP4 fallback مفعّل من البداية) حسب الملف الأم.
