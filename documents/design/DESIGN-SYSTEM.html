القاعدة: الصفحة ليست بيضاء

البيج الدافئ خلف الكروت البيضاء هو ما يجعل الكرت يُرى. لو صارت الخلفية بيضاء اختفت حدود الكروت واحتجت ظلالاً لتعويضها — وهنا يبدأ الانحدار.

عنوان البطاقة

٣ الظلال — أثقل تغيير، وأوضح دليل

صفر ظلّ داخل تدفّق الصفحة. الفصل يأتي من حلقة ١px. والظلّ محجوز لما يطفو فوق الصفحة.

✓ الصحيح

حلقة ١px تعطي حدّة ونظافة لا يعطيها الظلّ.

لماذا حلقة لا border؟

box-shadow لا تأخذ مساحة في التخطيط. تغيّر سمكها من ١px إلى ٢px عند التحويم بلا أن ينتفض العنصر ولا يزحف ما حوله.

✕ يسبّب ارتجاف التخطيط 
.btn       { border: 1px solid var(--blue) }
.btn:hover { border: 2px solid var(--navy) }
✓ صفر حركة 
.btn       { box-shadow: inset 0 0 0 1px var(--blue) }
.btn:hover { box-shadow: inset 0 0 0 2px var(--navy) }

٤ الطباعة

وزنان فقط، ونسبتان لارتفاع السطر. التمييز يأتي من الحجم واللون — لا من الوزن.

٤.١ الوزن — 400 و 700 فقط

لينكدإن يستعمل 400/600. ونحن لا نستطيع نسخها حرفياً، والسبب قياسيّ لا ذوقيّ:

معاينة — وزنان يكفيان

وزن ٤٠٠ — نصّ عاديّ، وهو الأغلبية الساحقة في أيّ صفحة.

وزن ٧٠٠ — عنوان أو تأكيد، ولا شيء بينهما.

التمييز من الحجم…

…ومن اللون. هذا يكفي لبناء تسلسل هرميّ كامل.

٤.٢ ارتفاع السطر — نسبتان لا واحدة

أذكى نقطة في النظام المقيس: نفس الحجم له ارتفاعان بحسب السياق. أغلب الأنظمة تعطي ارتفاعاً واحداً لكل حجم، فتخرج الواجهة فضفاضة أو المحتوى خانقاً.

--lh-tight:   1.25;  /* واجهة: أزرار · labels · عناوين بطاقات · سطر أو سطران */
--lh-relaxed: 1.5;   /* محتوى: فقرات · نصّ المقال · قراءة متواصلة */
معاينة — نفس الحجم ١٤px، سياقان

٨ اللمس — 48px لكل عنصر تفاعليّ

الشكل المرئيّ 32px، والغلاف الشفّاف 48px. المستخدم يرى زرّاً أنيقاً صغيراً، وإصبعه يصيب مساحة كبيرة.

زرّ بارتفاع 32px يسقط في معيار WCAG 2.5.5 (44×44 حدّاً أدنى). وبدل تكبيره بصرياً وإفساد الكثافة، يُلَفّ في هدف لمس أكبر.

<button className="flex min-h-[48px] items-center bg-transparent p-0">
  <span className="flex h-8 items-center rounded-full px-3">احجز</span>
</button>
