Master Rules / Modonty Icon DNA

  • One meaning. One shape. One Modonty signature.
  • Function must be understood first; Modonty identity second.
  • Primary: #0E065A (Deep Modonty Navy). Accent: #00D8D8 (Vibrant Cyan).
  • Minimal, rounded, strong silhouette, highly readable at 20–24px navigation scale.
  • Do not force the cyan diamond into every utility icon if it hurts clarity.
  • No 3D, shadows, glow or presentation gradients inside production SVG.
  • Approved visual is the absolute source of truth for production assets.
  • Never trust SVG text rendered inside AI presentation mockups; use exact geometric code.
  • When extracting, use the exact vector paths provided in each tab.

Construction Rules

  • Visual balance: visual weight is calibrated evenly across all 38 icons.
  • Monochrome compatibility: the icon function remains 100% understandable even in pure black/navy.
  • Diamond Role: The cyan diamond serves as a functional node, status marker, central trigger, or core branding focal point.
  • Scalability: No micro-lines that collapse below 18px render resolution.

Official Workflow

  1. Geometry grid definition (120x120px).
  2. Geometric vector blueprint creation.
  3. Harmonization of stroke width & corner curvature.
  4. Insertion of functional Modonty cyan diamond.
  5. Production SVG validation and metadata recording.
  6. Export to standalone HTML & React JSX components.
