# عقد قصة الشعار

كل علامة أو شعار في مدوّنتي أصل معرفي، وليس ملف رسم فقط. يجب أن تبقى الفكرة والهدف
والدلالة ملازمة له حتى إذا نُقل إلى تطبيق آخر، كما يجب أن تتوفر بصيغة منظمة لبناء صفحة
«علامات مدوّنتي وقصصها» لاحقًا.

## الملفان الإلزاميان

لكل أصل باسم `name.svg` يوجد بجواره:

1. **داخل SVG:** عناصر `title` و`desc` و`metadata` تحمل النسخة المختصرة من القصة.
2. **`name.story.json`:** المصدر المنظم الذي ستقرأ منه صفحة عرض الشعارات.

لا تعتمد الصفحة على قراءة XML من SVG وقت التشغيل؛ `story.json` أسرع وأوضح وأسهل في
التحقق والترجمة. الـmetadata داخل SVG طبقة حفظ وانتقال، وليس قاعدة بيانات للواجهة.

## حقول القصة

| الحقل | الغرض |
|---|---|
| `schemaVersion` | ترقية البنية مستقبلًا بدون كسر القصص القديمة |
| `slug` | معرّف ثابت للرابط والربط بين الأصل والقصة |
| `titleAr` | الاسم الرسمي الظاهر |
| `status` | `review` أو `approved` أو `retired` |
| `ideaAr` | الفكرة في جملة واحدة واضحة |
| `objectivesAr` | ماذا يجب أن يحقق الشعار للمستخدم والمنصة |
| `symbolismAr` | كل جزء في الشكل وما الذي يعنيه |
| `themeTokens` | رموز الألوان الدلالية؛ ممنوع Hex في مكوّن الواجهة |
| `usageAr` | أين يستخدم وأين لا يستخدم |
| `accessibilityAr` | الاسم المقروء وسلوك الزخرفة والتباين |
| `approval` | تاريخ الاعتماد ومن اعتمده؛ يبقى `null` قبل الموافقة |

## مثال metadata داخل SVG

```xml
<title id="title">علامة مجالات مدوّنتي</title>
<desc id="desc">ثلاث بوابات تمثل المجالات حول ماسة مدوّنتي</desc>
<metadata id="design-story">
  {"schemaVersion":1,"slug":"industries-mark","status":"review",
   "ideaAr":"ثلاث بوابات مختلفة تلتقي حول منصة واحدة"}
</metadata>
```

يوضع `aria-labelledby="title desc"` إذا استُخدم SVG كصورة مستقلة ذات معنى. داخل مكوّن
له نص مجاور يبقى الشعار زخرفيًا، ويأخذ العنصر التفاعلي اسمه من سياقه.

## قاعدة التطابق

- `slug` داخل SVG يطابق `slug` في `story.json`.
- أي تعديل في دلالة الشكل يحدّث الملفين في نفس قرار التصميم.
- تغيير المقاس أو تحسين مسار لا يغيّر القصة إن لم يتغير المعنى.
- لا تتحول حالة `review` إلى `approved` إلا بعد موافقة صريحة موثقة.
- لا تُحذف قصة شعار متقاعد؛ تتحول حالته إلى `retired` كي تبقى الذاكرة المؤسسية.
