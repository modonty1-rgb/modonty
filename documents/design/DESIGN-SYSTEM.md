## 0. من أين جاءت كل قيمة

ثلاثة مصادر، ولكلٍّ وزن مختلف عند التعارض:

| المصدر | ماذا يعطي | الوزن |
|---|---|---|
| **`modonty/app/globals.css`** | هويّتنا: الألوان والخط والقطر | **الأعلى** — هذا ما يعمل فعلاً |
| **مسح لينكدإن الحيّ** (`getComputedStyle`) | البنية: الظلال والأوزان والشبكة واللمس | يفوز حين لا يخصّ الهويّة |
| `DESIGN_SYSTEM.md` القديم | — | **مُلغى**: يوثّق `--primary: #0a66c2` بينما كودنا `#3030FF` |

**التحقّق من لينكدإن أُعيد على ثلاثة أسطح مستقلّة** لا على صفحة واحدة:

```
/feed/          1,588 عنصراً   (مسح مريم، ١٤ أغسطس)
/top-content/     424 عنصراً   (تحقّق مستقلّ)
/jobs/            312 عنصراً   (تحقّق مستقلّ)
```

ما تكرّر في الثلاثة يُعتمد. ما اختلف يُذكر اختلافه صراحةً.

## 1. الهويّة — من كودنا، لا تُستورد

```css
--brand-navy:  245 87% 19%;   /* #0B0A5C */
--brand-blue:  240 100% 59%;  /* #3030FF  ← primary */
--brand-teal:  180 100% 42%;  /* #00D8D8  ← accent  */
```

> ⚠️ الملف القديم كان يقول `--primary: 210 90% 40%  /* #0a66c2 - LinkedIn's signature blue */`.
> هذا لون منصّة أخرى. **لا يُنسخ لون علامة، ولا شعار، ولا أيقونة.** يُنسخ الهيكل فقط.

الخلفية والأسطح — وهنا نتّفق مع لينكدإن بالصدفة لا بالنقل:

```css
--background: 45 8% 95%;   /* #f3f2ef بيج دافئ */
--card:       0 0% 100%;   /* أبيض */
```

القاعدة: **الصفحة ليست بيضاء، والكروت بيضاء فوقها.** لو صارت الخلفية بيضاء اختفت الكروت.

## 2. الظلال — أثقل تغيير، وأوضح دليل

**القاعدة: صفر ظلّ داخل تدفّق الصفحة. الفصل يأتي من حلقة 1px.**

```css
--ring-card:   0 0 0 1px hsl(var(--border));            /* الكرت */
--ring-active: inset 0 0 0 1px hsl(var(--foreground));  /* الحالة النشطة */
--ring-brand:  inset 0 0 0 1px hsl(var(--primary));     /* الزر الثانوي */
```

الظلّ محجوز حصراً لما **يطفو فوق** الصفحة (قائمة منسدلة · toast · مشغّل عائم):

```css
--shadow-float: 0 0 1px rgba(0,0,0,.45), 0 4px 12px rgba(0,0,0,.6);
```

**لماذا حلقة لا `border`؟** لأن `box-shadow` لا تأخذ مساحة في التخطيط. تغيّر سمكها 1px→2px عند التحويم بلا أن ينتفض العنصر. `border: 1px → 2px` يقفز التصميم في كل مرة.

**الدليل المقيس:**
```
/feed/        1,588 عنصراً → صفر ظلّ حقيقي (blur>0) · 3 حلقات فقط
/top-content/   424 عنصراً → الظلال كلها من نمط  0px 0px 0px 1px
/jobs/          312 عنصراً → 29 حلقة + ظلّ عائم واحد rgba(0,0,0,.3) 0 4px 12px
```

**وضعنا الحالي:**
```
$ grep -rohE "shadow-(sm|md|lg|xl|2xl)" modonty/app modonty/components
  50 shadow-sm · 42 shadow-md · 25 shadow-lg · 3 shadow-2xl · 1 shadow-xl   = 121
```
١٢١ ظلّاً، ولا حلقة واحدة. والملف القديم يوصي بهذا صراحةً (`shadow-sm` للكرت، `hover:shadow-md`) — وهذه توصية تُلغى.

## 3. الطباعة

### ٣.١ الوزن — اثنان فقط: `400` و `700`

هنا **لا نستطيع نسخ لينكدإن حرفياً**، والسبب قياسيّ:

```
$ fonts.googleapis.com/css2?family=Tajawal:wght@600  →  HTTP 400
  المتاح في تجوّال: 200 · 300 · 400 · 500 · 700 · 800 · 900   — لا 600 إطلاقاً
$ layout.tsx:17   weight: ["400","500","700"]
```

فلينكدإن يستعمل `400/600`، ونحن نظيرها عندنا `400/700`.

**وهذا يكشف عيباً قائماً:**
```
$ grep -rohE "font-(semibold|extrabold|black)" modonty/app modonty/components
  176 font-semibold   ← وزن 600، غير موجود في تجوّال
   54 font-extrabold  ← 800، غير محمَّل
   33 font-black      ← 900، غير محمَّل
```
٢٦٣ موضعاً تطلب أوزاناً لا يملكها الخط، فيقرّبها المتصفّح أو يزيّفها. النتيجة ثِقَل غير متّسق يختلف بين جهاز وآخر.

| المستعمل الآن | البديل |
|---|---|
| `font-medium` · `font-semibold` | `font-bold` (700) |
| `font-extrabold` · `font-black` | `font-bold` (700) |

**التمييز يأتي من الحجم واللون، لا من الوزن.** هذا ما يجعل الصفحة هادئة وسهلة المسح بالعين.

### ٣.٢ ارتفاع السطر — نسبتان لا واحدة

أذكى نقطة في النظام المقيس: نفس الحجم له ارتفاعان بحسب السياق.

```css
--lh-tight:   1.25;   /* واجهة: labels · أزرار · عناوين بطاقات · سطر أو سطران */
--lh-relaxed: 1.5;    /* محتوى: فقرات · نصّ المقال · قراءة متواصلة */
```

مؤكَّد حيّاً: `14px/17.5px` (=1.25) ×34 و`16px/24px` (=1.5) ×194 على `/jobs/`.

**والعربي يحتاج `1.5` أكثر من اللاتيني** — التشكيل والنقاط تحت خطّ الأساس. لا تنزل تحت `1.5` في نصّ المقال.

### ٣.٣ السلّم

| الاسم | المقاس/السطر | الوزن | الاستعمال |
|---|---|---|---|
| caption | `12 / 15` | 400 | طوابع زمنية · ميتاداتا |
| ui | `14 / 17.5` | 400 · 700 | **الافتراضي** — أزرار · بطاقات صغيرة |
| body | `14 / 21` | 400 | نصّ طويل |
| title-sm | `16 / 20` | 700 | عناوين البطاقات |
| title-md | `20 / 25` | 700 | عناوين الأقسام |
| title-lg | `24 / 27` | 700 | عنوان الصفحة |

`letter-spacing: normal` في كل مكان. أيّ عبث بالتباعد يكسر العربي أولاً.

## 4. نصف القطر — ثلاث فئات، لا تُخلط

```
حاوية  (كرت · قسم · نافذة)          →  rounded-lg   (8px)
تحكّم  (زر · حقل · شارة · أفاتار)   →  rounded-full (999px)
مصغّرة (شعار كيان · thumbnail)      →  rounded-sm   (4px)
```

**أشيع خطأ:** `rounded-lg` على الأزرار. فتذوب داخل الكرت وتفقد «قابليّة النقر» البصريّة. التباين بين حاوية شبه مربّعة وتحكّم بيضاويّ تماماً هو ما يجعل الزرّ يقول «أنا زرّ».

**ملاحظة أمانة:** مقياس القطر **يختلف بين أسطح لينكدإن نفسها** — `/feed/` غالبه `999/4/8`، و`/top-content/` غالبه `16px`، و`/jobs/` غالبه `24px`. فالثابت ليس الرقم بل **قاعدة الفئات الثلاث**.

**وضعنا:** `rounded-full` ١٩٠ · `rounded-md` ١٥٠ · `rounded-lg` ٩٦ · `rounded-xl` ٨٥ · `rounded-2xl` ٦٤ — خمسة مقاسات للحاويات بلا قاعدة. تُوحَّد على `lg` للحاويات.

---

## 5. المسافات

أساس **4px** لا 8px صارم:

```
4 · 8 · 12 · 16 · 20 · 24 · 32
```

`16px` هو حشو الكرت الأفقي الأكثر استعمالاً · `24px` فجوة أعمدة الشبكة · `8px` بين كروت الشريط الجانبي.

---

## 6. التخطيط

```css
max-width: 1128px;   /* الحاوية */
column-gap: 24px;
row-gap: 16px;
```

`1128px` مؤكَّدة في الاثنين: `max-width: 1128px` ×12 على `/jobs/`، و`max-w-[1128px]` **٧٦ مرّة في كودنا**. هذه نقطة نتّفق فيها أصلاً.

**للعربي:** سمِّ المناطق `start`/`end` لا `left`/`right`، واستعمل `ps-` `pe-` `ms-` `me-`. الشبكة تنقلب مع `dir="rtl"` بلا إعادة تعريف.

---

## 7. اللمس — 48px لكل عنصر تفاعليّ

الشكل المرئيّ `32px`، والغلاف الشفّاف `48px`:

```tsx
<button className="flex min-h-[48px] items-center bg-transparent p-0">
  <span className="flex h-8 items-center rounded-full px-3">…</span>
</button>
```

زرّ بارتفاع 32 يسقط في معيار WCAG 2.5.5 (44×44 حدّاً أدنى). فبدل تكبيره بصرياً وإفساد الكثافة، يُلَفّ في هدف لمس أكبر. مؤكَّد حيّاً: ارتفاعات الأزرار على `/jobs/` تشمل **32** و**48**.

## 8. النصّ — شفافية لا ألوان صريحة

```
rgba(0,0,0,.9)  → أساسي     ← /feed/ ×985 · /top-content/ ×224
rgba(0,0,0,.75) → ثانوي     ← ×234 · ×67
rgba(0,0,0,.6)  → ثالثي     ← ×228 · ×84
```

النسبة ٤:١:١ — الأغلبية نصّ أساسيّ. **لا تجعل الصفحة كلها رمادية «عشان تبان ناعمة»** فتفقد التسلسل الهرميّ.

**لماذا شفافية؟** نفس القيمة تعمل فوق الأبيض والبيج معاً. اللون الصريح ينكسر فوق أحدهما.

**وضعنا:** `--foreground: 245 87% 19%` كحليّ صريح، و`--muted-foreground: #5b5b5b`. الكحليّ **قرار هويّة نبقيه**؛ لكن الدرجات الثلاث تُبنى منه بالشفافية لا بألوان جديدة:

```css
--text-1: hsl(var(--foreground) / .9);
--text-2: hsl(var(--foreground) / .75);
--text-3: hsl(var(--foreground) / .6);
```

## 9. الحركة

```css
--ease: cubic-bezier(.34, 0, .21, 1);
--duration: .216s;
```

`transition` على **خاصيّة محدّدة**، لا `all` — فـ`all` يحرّك ما لا تقصده ويكلّف رسماً زائداً.

## 10. قائمة التحقّق قبل أيّ شاشة

- [ ] صفر `shadow-*` داخل التدفّق — حلقة `ring` بدلها
- [ ] الظلّ للطبقات العائمة فقط
- [ ] التحويم يغيّر سمك الحلقة لا سمك الحدّ
- [ ] وزنان: `font-normal` و`font-bold` — صفر `semibold`/`extrabold`/`black`
- [ ] `1.25` للواجهة · `1.5` للمحتوى
- [ ] حاوية `rounded-lg` · تحكّم `rounded-full` · مصغّرة `rounded-sm`
- [ ] كل تفاعليّ في هدف لمس `48px`
- [ ] `ps/pe/ms/me/start/end` — صفر `left`/`right`
- [ ] الحاوية `max-w-[1128px]`
- [ ] الألوان من `globals.css` — صفر لون مكتوب باليد

## 11. الأخطاء الخمسة التي تكسر النظام

| # | الخطأ | الأثر | الصحيح |
|---|---|---|---|
| ١ | `shadow-sm` على الكرت | الشكل يصير «قالب مجاني» | `ring-1 ring-border` |
| ٢ | خلفية الصفحة بيضاء | الكروت تختفي | `bg-background` البيج |
| ٣ | `rounded-lg` على الأزرار | الزرّ يذوب في الكرت | `rounded-full` |
| ٤ | `font-semibold` | وزن لا يملكه تجوّال → تزييف | `font-bold` |
| ٥ | `border: 1px → 2px` عند التحويم | ارتجاف التخطيط | `ring` بدل `border` |

## 12. ما لم يُتحقّق منه بعد

أمانةً — هذه ادّعاءات في المسح الأصلي لم أُعِد قياسها:

- شبكة **٢٤ عموداً** بعرض مسار `17.01px` — قِيست على `/feed/` عند `1117px` فقط، ولم أتحقّق منها على سطح آخر.
- ارتفاع شريط التنقّل `52px`.
- تفصيل ألوان أيقونات المُنشئ (`#44712E` · `#B24020`).

استعملها كإرشاد، لا كقاعدة، حتى تُقاس ثانيةً.
