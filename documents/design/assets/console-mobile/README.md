# Console Mobile — مراجع التصميم

## الهيكل

- `approved/`: الشاشة المعتمدة فقط، مباشرةً باسمها الثابت. هي عقد التنفيذ والمقارنة على جهاز Android.
- `in-review/`: الشاشات التي نراجعها الآن فقط، مباشرةً باسمها الثابت. `SCREEN-SCAN.png` لوحة الفهرسة هنا.
- `rejected/`: تصميمات ملغية أو قديمة، معزولة عن العمل الحالي.

## الحالة الحالية

- المعتمد: `S00-foundations.png` و`S01-login.png` و`S02-home.png` و`S03-referral-message.png` و`S04-subscription.png` و`S05-decision-articles.png` و`S06-review-hub.png` و`S07-article.png` و`S07-questions.png` و`S07-citations.png` و`S08-audience.png` و`S08-audience-reply.png`.
- المراجعة التالية: `S09` حتى `S14`.

عند اعتماد شاشة تُنقل من `in-review/` إلى `approved/` بالاسم الثابت نفسه. لا توجد نسخ مكررة أو مجلدات إصدارات ضمن العمل النشط.
