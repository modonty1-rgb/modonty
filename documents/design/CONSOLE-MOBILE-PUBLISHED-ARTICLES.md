## المعاينة

`assets/console-mobile/rejected/console-mobile-published-articles-v1.png`

هذه معاينة قديمة ملغية، محفوظة للتاريخ فقط. لا يبدأ أي تنفيذ منها.

## النطاق

- شاشة تاب المقالات المنشورة في `console-mobile` فقط.
- المقالات المنشورة تعرض نتيجة المحتوى وسياقها.
- المقالات بانتظار التعميد أو التي تحتاج تعديلاً خارج هذا التصميم؛ تبقى داخل التطبيق في مسار المراجعة.

## التشريح المعتمد

| العنصر | القرار |
|---|---|
| شريط التطبيق | محتوى `56dp` مع `insets.top`؛ هوية العميل والشعار ورمز تحكم واحد ضمن أهداف لمس `48×48dp`. |
| عنوان الصفحة | من API، محاذى RTL، Tajawal `18/26` بوزن `500`. |
| القائمة | `FlashList`؛ حواف الشاشة `16` وفاصل البطاقات `12`. |
| بطاقة المقال | سطح هادئ للعرض، زاوية `20` وحشو `16`. لا تجعل البطاقة نفسها انتقالاً خفياً. |
| الصورة | `featuredImage` أعلى البطاقة بنسبة `16:9`، وتحذف عند غيابها. |
| معلومات المقال | التصنيف وتاريخ النشر، ثم عدد الكلمات إذا أعاده API؛ الغائب يحذف ولا يملأ. |
| عنوان المقال | Tajawal `16/24` بوزن `500`، سطران ثم `…`. |
| الوصف | Tajawal `15/23` بوزن `400`، سطران ثم `…`. |
| فعل التنقّل | زر ثانوي صريح من مصدر API داخل البطاقة المنشورة فقط، بارتفاع `56dp` وهدف لمس لا يقل عن `48×48dp`. يفتح `articlesBaseUrl` الفعلي لموقع العميل في المتصفح. إن غاب الرابط أو النص من المصدر، يحذف الزر. |
| التنقل السفلي | محتوى `64dp` مع `insets.bottom`؛ أيقونة بصرية `24dp` داخل هدف لمس `48×48dp` وتسمية `11/16`. |
| أفاتار العميل | يبقى كهوية العميل من المصدر الحقيقي، **بلا حلقة خضراء سميكة أو إطار أكسنت**؛ لا يمثل حالة أو فعلاً. |

## مبادئ Material المطبقة

- البطاقة مدخل واحد لموضوع واحد، ولها فعل واحد صريح لا يزاحم المحتوى: فتح موقع العميل.
- العنوان والمعلومات الثانوية والنص المقروء مستويات مستقلة؛ الوزن ليس زينة.
- الرمز البصري أصغر من هدف لمسه، ولا تنافس الأيقونات العنوان أو المقال.

المرجع: [MUI Card](https://mui.com/material-ui/react-card/) و[Typography](https://mui.com/material-ui/react-typography/). عند التعارض، تفوز الأرقام الحاكمة في `documents/mobile/UIUX-RULES.md` على نظام التصميم العام أو MUI.
