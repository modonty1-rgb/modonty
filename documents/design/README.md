# مرجع التصميم — نقطة الدخول الإلزامية

هذا المجلد هو المرجع الثابت لأي قرار بصري في مدوّنتي. قبل اقتراح واجهة أو شعار أو
مكوّن، تُقرأ هذه الصفحة ثم `DESIGN-SYSTEM.md`، وبعدها ورقة العنصر المعني إن وُجدت.

## ترتيب المرجعية

1. `DESIGN-SYSTEM.md` — الألوان والطباعة والمسافات والحركة وقواعد الواجهة العامة.
2. ورقة العنصر داخل هذا المجلد — المعنى والهندسة والحالات والمقاسات الخاصة به.
3. المعاينات داخل `assets/` — دليل بصري للمراجعة، وليست ملفات إنتاج.
4. كود التطبيق — تنفيذ للقرار المعتمد، وليس مصدرًا لاختراع قرار جديد.

عند التعارض يفوز الأعلى في القائمة، ويُسجّل سبب تعديل المرجع قبل تغيير التنفيذ.

## دورة أي عمل تصميمي

| المرحلة | الناتج | هل يُسمح بتعديل التطبيق؟ |
|---|---|---|
| `IDEA` | شرح المشكلة وفكرة أولية | لا |
| `REVIEW` | معاينة + قواعد قابلة للقياس | لا |
| `APPROVED` | موافقة صريحة من خالد على المعاينة | لا، حتى يطلب التنفيذ |
| `IMPLEMENT` | خالد يقول «نفّذ» أو «do» | نعم، في النطاق المتفق عليه فقط |
| `VERIFIED` | خالد يطلب «تحقق» أو `check` | نعم، للتحقق فقط |

### حاجز الموافقة

- «تمام» أو «الفكرة مناسبة» أو الموافقة على صورة تعني اعتماد الاتجاه البصري فقط.
- لا يُعدّل كود أو أصل إنتاجي حتى تأتي كلمة تنفيذ صريحة بعد عرض نطاق الملفات.
- أي SVG داخل `documents/design/assets/` هو **معاينة غير إنتاجية** حتى تُنقل نسخة معتمدة
  إلى مكانها في التطبيق بعد أمر التنفيذ.
- لا تحديث حزم من أجل عمل تصميمي. يُستعمل ما هو موجود في المشروع فقط.

## محتويات المرجع

| الملف | النطاق | الحالة |
|---|---|---|
| `DESIGN-SYSTEM.md` | النظام العام | معتمد؛ يتطور بالتوثيق |
| `INDUSTRIES-MARK.md` | علامة مجالات مدوّنتي | `APPROVED` — أصل SVG جاهز، غير مدمج بالكود |
| `PARTNERS-MARK.md` | علامة شركاء مدوّنتي | `APPROVED` — أصل SVG جاهز، غير مدمج بالكود |
| `LOGO-STORY-CONTRACT.md` | البيانات الملازمة لكل شعار وصفحة قصص العلامات | معتمد كقاعدة توثيق |

## قالب ورقة عنصر جديد

كل عنصر جديد يوثّق: المشكلة، المعنى، التشريح، شبكة القياس، الألوان، المقاسات، النسخ،
الحالات، الوصول، الممنوعات، حالة الموافقة، ونطاق التنفيذ المتوقع. لا تُستخدم أوصاف
انطباعية مثل «أجمل» أو «أخف» وحدها؛ كل قرار يجب أن يكون قابلاً للقياس أو المقارنة.

كل لون داخل مكوّن واجهة إنتاجي يجب أن يأتي من token دلالي أو `currentColor`. وجود قيمة
Hex في لوحة معاينة أو ملف هوية للطباعة لا يجيز نسخها hard-coded إلى React أو Tailwind.

كل شعار جديد يتبع `LOGO-STORY-CONTRACT.md`: قصة مختصرة داخل SVG وملف
`name.story.json` ملاصق له. الشعار بلا قصة وهدف وحالة اعتماد أصل غير مكتمل.
