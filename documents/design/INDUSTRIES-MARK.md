## الفكرة

ثلاث بوابات مستقلة ومتطابقة تمثل اختلاف المجالات، مرتبة حول مركز واحد يمثل منصة مدوّنتي.
الماسة السماوية في المركز هي نقطة مدوّنتي الأصلية، فتربط العلامة الجديدة بالهوية بدون
نسخ حرف `M` أو استخدام درع لا يحمل معنى للمجالات.

## التشريح والهندسة

- الشبكة المرجعية: `100 × 100` وحدة.
- مركز الدوران: `(50, 50)`.
- كل بوابة نسخة واحدة تدور `120°` ثم `240°؛` لا تُرسم البوابات يدويًا كل واحدة وحدها.
- مسار البوابة الأساسي: قوس بيضاوي متزن متصل بذراعين مستقيمين متساويين.
- سماكة المسار: `8.5` وحدة، لتظل الفراغات واضحة عند التصغير.
- النهايات والوصلات: دائرية وبنصف قطر واحد، لمنع الزوايا المكسورة عند التصغير.
- الماسة: مربع `15 × 15` وحدة، مدوّر `45°` حول المركز.
- المساحة حول الماسة متساوية بصريًا من الجهات الست، ولا تتصل بالبوابات.
- مساحة الأمان: لا يدخل أي عنصر آخر في إطار يبعد `12%` من حدود العلامة.

هذه النسب تجعل الخط قريبًا من `1.75px` عند عرض `16px`، فيبقى الشكل مقروءًا على
الموبايل. الماسة هي نقطة الارتكاز البصرية، والبوابات الثلاث هي البنية الحاملة للمعنى.

## الألوان

| الجزء | رمز الإنتاج | النتيجة |
|---|---|---|
| البوابات | `hsl(var(--foreground))` أو `currentColor` | كحلي في الفاتح، وفاتح عالي التباين في الداكن |
| ماسة مدوّنتي | `hsl(var(--accent))` | سماوي البراند بدرجته المناسبة لكل theme |
| الخلفية | شفافة | لا مربع أبيض ولا حاوية مدمجة في الأصل |

الأيقونة الإنتاجية **ديناميكية بالكامل**: لا تحتوي `#0E065A` ولا `#00D8D8` ولا أي لون
hard-coded. القيم اللونية المكتوبة في لوحة المعاينة مستقلة فقط كي تُعرض خارج التطبيق؛
عند التنفيذ يقرأ Inline SVG الرموز الدلالية من `modonty/app/globals.css`. لا تُستخدم
تدرجات أو ظلال أو شفافية داخل العلامة.

لا تُعرض الأيقونة كملف `<img src="...svg">` داخل الواجهة لأن CSS الصفحة لا يعبر إلى
داخل SVG الخارجي. المكوّن يكون Inline SVG حتى يستجيب للـtheme لحظيًا بلا نسختين وبلا
JavaScript لمراقبة الوضع.

## النسخ المطلوبة بعد الاعتماد

| النسخة | متى تستخدم |
|---|---|
| `adaptive` | النسخة الأساسية لكل واجهات المشروع؛ تتبع `foreground` و`accent` تلقائيًا |
| `mono` | طباعة بلون واحد أو حالات تقنية لا تسمح بلونين |
| `export` | مواد ثابتة خارج التطبيق فقط؛ تُولّد من رموز الهوية وقت التصدير ولا تدخل الواجهة |

لا تُنشأ النسخ الإنتاجية قبل اعتماد الشكل وأمر «نفّذ».

## المقاسات

| السياق | المقاس المرئي | الملاحظة |
|---|---:|---|
| أيقونة واجهة صغيرة | `16px` | الحد الأدنى للنسخة ثنائية اللون |
| صف أو زر | `20–24px` | المقاس الافتراضي |
| بطاقة مجال | `32–48px` | بلا تغيير في سماكة SVG |
| هوية قسم | `64px+` | نفس الهندسة، بلا تفاصيل إضافية |

- تحت `12px`: تستعمل النسخة الأحادية؛ النسخة ثنائية اللون معتمدة من `16px` فما فوق.
- حجم الأيقونة لا يساوي هدف اللمس؛ العنصر التفاعلي يظل `44–48px` على الأقل.
- لا تُستخدم صورة PNG داخل الواجهة عندما يتوفر SVG.

## الوصول

- إذا كان بجانب العلامة نص «المجالات»، تعامل كزخرفة: `aria-hidden="true"`.
- إذا ظهرت وحدها كرابط، يأخذ الرابط اسمًا واضحًا مثل `aria-label="استكشف المجالات"`.
- لا تعتمد الحالة أو المعنى على السماوي وحده؛ الشكل نفسه يحمل المعنى.
- النسخة `adaptive` هي الافتراضية دائمًا: في الوضع الداكن تتحول البوابات تلقائيًا إلى
  `foreground` الفاتح، وتتبع الماسة `accent` الداكن. لا يختار المستهلك ألوانًا يدوياً.

## افعل / لا تفعل

| افعل | لا تفعل |
|---|---|
| حافظ على الدوران `120°` | لا تحرك بوابة وحدها |
| اترك الخلفية شفافة | لا تدمج مربعًا أبيض أو حوافًا دائرية |
| حافظ على ماسة المركز بحجم `15` | لا تغيّر نسبتها أو تجعلها تلامس البوابات |
| استخدم `foreground` و`accent` | لا تكتب Hex أو لون Tailwind مباشر داخل المكوّن |
| صغّر SVG نفسه | لا ترسم نسخة مختلفة لكل مقاس |
| ضع مساحة أمان `12%` | لا تلصق نصًا أو إطارًا بالعلامة |
| استخدم لونين مسطحين | لا تضف gradient أو shadow أو 3D |

## قرار الاعتماد

اعتمد خالد الاتجاه النهائي: ثلاث بوابات منفصلة، نهايات دائرية، سماكة `8.5`، وماسة
مركزية كبيرة بحجم `15`. الأصل موجود في `shared/assets/brand/` لتسليمه إلى كلود؛ لم
يُعدّل أي مكوّن أو سجل أيقونات داخل التطبيقات.
