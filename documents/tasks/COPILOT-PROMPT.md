# كوبايلوت — خمس بطاقات سيو في الأدمن

اقرأ هذا الملفّ كاملاً قبل أن تكتب سطراً واحداً. لا تبدأ بتلخيصه، ولا تسألني إن كنت أريدك أن تبدأ — ابدأ بالبطاقة الأولى وطبّق ما فيه.

أنت رابع من يشتغل على الفرع `modonty-ui`: كلود وكودكس ووكلاء انتهوا، وأنت. **الفصل بينكم بالمنطقة لا بالملف** — من التزم بمنطقته لا يلتقي بأحد. من خرج منها يكسر شغل غيره، وقد حصل اليوم: عامل استعمل متغيّراً خارج نطاق تعريفه، وكان سيُعطّل توليد بيانات كل المقالات لولا أن المترجم أمسكه.

## 🚫 الممنوعات — كل واحدة منها تُوقف شغلك فوراً

| ممنوع | السبب |
|---|---|
| `shared/` بكل ما فيه | ثلاثة تطبيقات تقرأ منه — تعديل واحد يكسر ثلاثة |
| `modonty/` بكل ما فيه | نطاق كلود وكودكس |
| `admin/lib/seo/listing-page-seo-generator.ts` · `category-seo-generator.ts` · `tag-seo-generator.ts` · `industry-seo-generator.ts` · `article-validator-db.ts` · `ymyl-helpers.ts` | كلود يشتغل فيها الآن |
| `admin/app/(dashboard)/modonty/setting/helpers/**` | كلود وكودكس |
| `schema.prisma` وأي تعديل سكيما | يحتاج طقس إيقاف السيرفرات وإعادة التوليد — ليس شغلك |
| أي كتابة في قاعدة البيانات | القاعدة المفعَّلة `modonty_dev`؛ لا تكتب فيها ولو تجربةً |
| `git add` · `git commit` · `git push` · تبديل فرع · `git checkout` | كلود يثبّت ويدفع بأمر خالد وحده |
| `pnpm build` · تنصيب حزم · ترقية أي شيء · تعديل `package.json` | خارج مهمّتك تماماً |

**لو احتاجت البطاقة ملفّاً ممنوعاً:** قف. اكتب اسم الملفّ في تقريرك وانتقل للبطاقة التالية. **لا تعدّله «لأن التعديل بسيط».**

## 🔴 القاعدة الأولى: ممنوع hardcode — كل نصّ يصل جوجل مصدره القاعدة

هذي أهمّ قاعدة في المشروع، وخالد ثبّتها اليوم. المعمار عندنا:

> الأدمن يحسب الميتاداتا والبيانات المنظَّمة **مرّة واحدة عند الحفظ** ويخزّنها في القاعدة، ومدونتي تقرأ المخزَّن جاهزاً.

فأي نصّ تكتبه في الكود **يتجاوز هذي الدورة كلّها** ويصير قيمة لا يقدر أحد يعدّلها من الأدمن.

**والاحتياطي هو نفسه المخالفة.** لا فرق بين قيمة ثابتة وقيمة ثابتة تظهر عند الغياب — الاثنتان نصّ يصل جوجل ولا يملكه صاحب الموقع:

```ts
// ❌ ممنوع — نصّ في الكود
const description = row.seoDescription || `تصفح مقالات ${row.name}`;

// ✅ الصحيح — الحقل يُحذف عند الغياب
const description = row.seoDescription?.trim() || undefined;
...(description && { description }),
```

**الغياب يبقى غياباً.** الحقل يُملأ من شاشة الأدمن، لا من ملفّ كود.

الاستثناء الوحيد: قيمة بنيوية ينكسر الموقع بدونها (`siteUrl`) — وليست نصّاً تحريرياً.

## 🚫 بوّابة قبل أي تعديل — ممنوع التخمين

قبل ما تكتب سطراً على أي بطاقة، جاوب الثلاثة **مكتوبةً في تقريرك**:

1. **هل أعدتُ إنتاج العطل؟** بأمر حقيقي وناتج خام. «الكود يبدو غلطاً» ليس إعادة إنتاج.
2. **ما المصدر الرسمي الذي يقول إن هذا غلط؟** رابط + الجملة المقتبسة حرفياً. جوجل أو schema.org أو توثيق Next.js فقط. **لا مدوّنات ولا Stack Overflow ولا ذاكرتك.**
3. **هل الملفّ داخل صلاحياتي؟** لو لا — قف واكتب اسمه.

**البطاقة قد تكون غلطاً.** لو قِستَ فما وجدتَ العطل — **لا تصلح شيئاً**. اكتب «ما قدرتُ أعيد إنتاجها» مع الناتج الخام. هذا تسليم صحيح لا فشل: حصل أربع مرّات اليوم مع عمّال آخرين، وكانوا محقّين في كل مرّة، ومرّتان منها كانت البطاقة نفسها غلطاً.

## 🚦 علمان إلزاميان — ابدأ وارفع، خلّص وارفع

خالد يفتح اللوحة ليعرف أي بطاقة تحت الشغل الآن بلا أن يسأل أحداً.

**قبل ما تبدأ بطاقة** — في `documents/tasks/task-data.json`، ابحث عن بطاقتك بـ`"id"` وأضف عليها:

```json
"working": true
```

**لحظة ما تخلّصها** — على نفس البطاقة:

```json
"working": false,
"ready": true
```

**وبعد كل خطوة من الاثنتين شغّل:**

```bash
cd documents/tasks && node build-task-board.mjs
```

`working` و`ready` هما **الحقلان الوحيدان** المسموح لك بكتابتهما في ذلك الملفّ.

**بطاقة واحدة برتقالية في المرّة.** فتح بطاقتين معاً يعني أن أحداً لا يعرف أين أنت.

**لا تنتظر جواب كلود** — ارفع الأخضر وابدأ التالية فوراً.

## التحقّق

السيرفران شغّالان: `localhost:3000` مدونتي · `localhost:3001` الأدمن. قِس بـ`curl` — لا ترقّي شيئاً ولا تنصّب شيئاً ولا تشغّل المترجم (كلود يشغّله قبل الدفع).

⚠️ الوسوم تُرسَم بحالة أحرف React: `hrefLang` لا `hreflang`. استخدم `grep -i` دائماً — كلود انخدع بهذا اليوم وأعلن إنذاراً كاذباً.

⚠️ ملفّات المستودع بنهايات أسطر `CRLF`. أي بحث أو استبدال بـ`\n` وحده **لن يطابق شيئاً** وقد يوهمك بالنجاح — كلود وقع فيها اليوم.

## المخرَج — ستّة أسطر لكل بطاقة، بلا زيادة

```
البند: <id>
الملفات: <ملف:سطر>
قبل: <ناتج خام>
بعد: <ناتج خام>
المصدر: <رابط + الجملة المقتبسة حرفياً>
ما لم يُقَس: <إلزامي — ما الذي لم تتحقّق منه>
```

**سطر «ما لم يُقَس» إلزامي في كل بطاقة.** تقرير بلا هذا السطر مردود بلا قراءة.

**ولا تكتب «تمّ» ولا «يعمل الآن» بلا ناتج خام تحته.** الجدول وعلامة ✅ لا تُحسبان دليلاً — أنت الذي تكتبهما.
