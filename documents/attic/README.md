# العلّية — ملفّاتٌ نُقلت من جذر المستودع

نُقلت هنا في ١٥ سبتمبر ٢٠٢٦ لا حُذفت: متعقَّبة في git وصفر مراجع في الكود
(`git grep`)، فلا يكسر نقلها شيئاً — ولكنّها ليست ملكي فلا أحذفها.

- `nextjs.yml` — تعريف وكيلٍ (اسم · وصف · وسوم)، ليس ورك-فلو. لا `.github/workflows/`
  في المستودع أصلاً، فوجوده في الجذر لم يكن يشغّل شيئاً.
- `seo-devnadish-lines.json` — جرد سلاسل واجهة (قائمة `lines`)، مخرج عمليةٍ لمرّة.

احذفهما متى شئت، أو أعدهما إن كنت تستعملهما من خارج المستودع.
