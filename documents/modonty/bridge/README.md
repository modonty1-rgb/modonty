# الجسر — Claude ↔ Codex

قناة عمل واحدة بين مساعدَين يشتغلان على نفس المستودع من مجلّدين منفصلين. خالد هو الناقل: يأخذ الملف من صندوق ويسلّمه للطرف الآخر.

```
modonty/documents/bridge/
├── README.md              ← هذا الملف: القواعد والصيغ
├── CODEX-PROMPT.md        ← النصّ الذي يُسلَّم لـCodex مرة واحدة
├── outbox/                ← Claude يكتب هنا: مهامّ وأجوبة  →  إلى Codex
├── inbox/                 ← Codex يكتب هنا: تسليمات وأسئلة  →  إلى Claude
└── assets/                ← مخرجات Codex: صور ومرئيات
```

---

## السياج — بالمسار لا بالنيّة

| | يكتب في | ممنوع عليه |
|---|---|---|
| **Claude** | `modonty/` · `admin/` · `console/` · `dataLayer/` · `documents/` | — |
| **Codex** | `modonty/documents/bridge/inbox/` · `modonty/documents/bridge/assets/` · `.playwright-mcp/` | **أي ملف يُشحن**: `app/` · `components/` · `lib/` · `dataLayer/` · `*.config.*` · `package.json` |

السياج بالمسار يُفحص بأمر واحد ولا يحتاج ثقة:

```bash
git diff --name-only | grep -v '^modonty/documents/bridge/' | grep -v '^\.playwright-mcp/'
# أي سطر يظهر = خروج عن السياج
```

**ممنوع منعاً باتاً على الطرفين:** أي `merge` أو `rebase` أو دفع إلى `main`. الدمج بأمر خالد وحده، ولكل مرة أمر جديد.

---

## الدورة

1. **Claude** يكتب مهمة في `outbox/` باسم `YYYY-MM-DD-NN-<slug>.md`.
2. **خالد** ينقلها لـCodex.
3. **Codex** ينفّذ، يحفظ مخرجاته في `assets/`، ويكتب تسليمه في `inbox/` بنفس الرقم.
4. **خالد** يبلّغ Claude.
5. **Claude** يفحص التسليم مقابل معيار القبول، ويردّ في `outbox/` بـ«مقبول» أو «يحتاج إعادة» مع السبب.

الرقم `NN` يربط المهمة بتسليمها وبالردّ — ثلاثة ملفات بنفس الرقم.

## قواعد ثابتة على Codex

1. **لا تخمين.** ما لا يتضح في المهمة → سؤال في `inbox/`، لا اجتهاد.
2. **مصدر رسمي قبل أي ادّعاء على مكتبة.** لا حكم من الذاكرة.
3. **لا تسجيل ولا دفع** إلا لما تحت `modonty/documents/bridge/`، وبعد إذن خالد.
4. **العربية نصّاً بشرياً:** كلام يُقال بصوت عالٍ، بلا لغة أدبية ولا صياغة إدارية.
5. **الحدود مقدَّسة:** لمس ملف خارج السياج = المهمة مرفوضة كاملةً مهما كانت جودتها.
