# توثيق الصفحة الرئيسية

> **القارئ الأول لهذا المجلّد هو الوكيل (كلود)، لا الإنسان.**
> غرضه أن يفتح الوكيل ملفاً واحداً بدل ما يمشّط عشرات الملفات كل جلسة —
> فيوفّر توكن ووقتاً وفلوساً. المبرمج الجديد وتطبيق الجوّال مستفيدان ثانيان.

## الملفات

| الملف | إيش فيه | متى يُفتح |
|---|---|---|
| [MAP.md](./MAP.md) | كل ملف بسطر · حقائق مقيسة · مصائد | **أول ما تبدأ شغلاً على الرئيسية** |
| [api-articles.md](./api-articles.md) | عقد `GET /api/articles` كاملاً | عند بناء الجوّال أو تعديل الرابط |
| [data-flow.md](./data-flow.md) | من وين تجي بيانات كل قسم | عند تغيير مصدر بيانات |
| [refactor-log.md](./refactor-log.md) | تاريخ إعادة الهيكلة: كل قرار بسببه ودليله | لمّا تسأل «ليش هذا على هذا الشكل؟» |

> **ليس هنا:** الشغل المفتوح — مكانه `TASK.md` في جذر المسار.

## قاعدة الصيانة (الأهمّ)

أي تعديل يغيّر ملفاً أو دالّة أو رقماً مقيساً → **حدّث السطر المقابل في نفس الكوميت.**
توثيق قديم أسوأ من لا توثيق، لأنه يُصدَّق ويُبنى عليه.

## قاعدة الكتابة

كل ملف يجاوب سؤالاً واحداً. كل حقيقة معها دليلها وتاريخها.
ولو احتجت فقرتين لشرح شي، فالشي نفسه معقّد — بسّطه بدل ما تشرحه أكثر.
