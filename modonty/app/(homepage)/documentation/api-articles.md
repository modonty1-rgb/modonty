# `GET /api/articles`

صفحة واحدة من قائمة المقالات. الرابط عامّ — أي عميل يقدر يناديه، وهو المخصّص
لتطبيق الجوّال القادم.

**الملف:** `app/(homepage)/api/articles/route.ts`
**الدالّة اللي يناديها:** `app/(homepage)/data/get-more-articles.ts` — وهي نفسها
اللي يناديها الموقع، فالمنطق مكتوب مرّة واحدة.

---

## المدخلات

| المعامل | إلزامي | الافتراضي | الشرح |
|---|---|---|---|
| `page` | لا | `1` | رقم الصفحة. عدد صحيح موجب |
| `category` | لا | — | تصفية بتصنيف (بالـ`slug`) |
| `client` | لا | — | تصفية بشريك (بالـ`slug`) |

حجم الصفحة ثابت في `lib/queries/feed-constants` — لا يُمرَّر من الخارج عمداً،
عشان ما يقدر أحد يطلب ألف مقال في نداء واحد.

---

## المخرجات

```jsonc
{
  "articles": [
    {
      "id": "…",
      "title": "…",
      "excerpt": "…",
      "image": "…",
      "slug": "…",
      "publishedAt": "2026-08-15T…",
      "clientName": "…",
      "clientSlug": "…",
      "clientLogo": "…",
      "readingTimeMinutes": 5,
      "hasAudio": false,
      "author": { "id": "…", "name": "…", "company": "…", "avatar": "…" },
      "likes": 0, "dislikes": 0, "comments": 0, "favorites": 0, "views": 1,
      "status": "published"
    }
  ],
  "hasMore": true
}
```

`hasMore` تقول هل فيه صفحة بعدها — يعتمد عليها التمرير اللانهائي.

---

## الحالات

| الحالة | متى |
|---|---|
| `200` | نجاح |
| `400` | `page` ليس عدداً صحيحاً موجباً — الجسم `{"error":"page must be a positive whole number"}` |

عند فشل القاعدة ترجع الدالّة قائمة فارغة و`hasMore: false` بدل ما ترمي خطأ،
فالواجهة ما تنكسر — والخطأ يُسجَّل في سجلّ الخادم.

---

## مقيس حيّاً (١٥ أغسطس ٢٠٢٦)

```
GET /api/articles?page=1     → 200 + مقالات
GET /api/articles?page=2     → 200
GET /api/articles?page=abc   → 400 + رسالة الخطأ
```

---

## للجوّال

- الرابط عنوان ثابت — **لا يتغيّر** ولو أعدنا ترتيب مجلّدات الموقع. القوسان في
  `(homepage)` لا يظهران في العنوان، وهذا مقصود.
- لا يحتاج مصادقة — المقالات المنشورة عامّة.
- لا تنادِ `server action` من الجوّال؛ هي للويب فقط. هذا الرابط هو بابك.
