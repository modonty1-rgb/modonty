# مسار المقال الواحد — الخريطة

> وُلِّدت من الشجرة نفسها في ١٩ أغسطس ٢٠٢٦ بعد ضبط البنية.
> **الملفّ ادّعاء لا دليل** — تحقّق من أي سطر قبل أن تبني عليه.

## القاعدة التي أُعيد ترتيب المسار عليها

| المجلد | ماذا يسكنه |
|---|---|
| `data/` | كل ما يجيب بيانات من السيرفر إلى الواجهة — دالّة واحدة لكل ملفّ |
| `actions/` | الكتابة وحدها (`"use server"`) — إعجاب، تعليق، ردّ |
| `helpers/` | أدوات صغيرة: تنظيف، تحقّق، توليد بيانات منظَّمة |
| `components/` | مجلد لكل شيء يراه الزائر، والملفّ بداخله PascalCase |
| `api/` | نقاط عامّة يناديها عميل خارجي (الجوّال) |

## البيانات (`data/`)

| الملفّ | يعطي |
|---|---|
| `get-article-content-by-slug.ts` | جسم المقال المخبّأ (`cacheLife("hours")` + وسم `articles`) |
| `get-article-by-slug-minimal.ts` | المخبّأ + العدّادات الحيّة + تفاعل هذا الزائر |
| `get-article-slugs-for-static-params.ts` | كل السلاگات لـ`generateStaticParams` |
| `get-article-faqs.ts` | الأسئلة المنشورة المُجابة |
| `get-article-comments.ts` | التعليقات المعتمَدة مرتّبة، وكل ردّ يحمل اسم من يردّ عليه |
| `fetch-article-comments.ts` | الباب الذي يناديه المتصفّح (`"use server"`) للتعليقات |
| `get-related-articles-by-author.ts` · `-by-client.ts` | «اقرأ له أيضاً» · «من نفس الشريك» |
| `get-related-articles-by-article-id.ts` | «ذات صلة» بثلاث حلقات: الوسوم ← التصنيف ← الأحدث |
| `get-pending-faqs-for-current-user.ts` | أسئلة هذا الزائر التي تنتظر ردّ الشريك |

## مشتركات رُقّيت خارج المسار

`lib/queries/get-article-for-chat.ts` و`get-articles-for-out-of-scope-search.ts` —
مستهلكهما `modo-chat`، ومسار لا يستورد من مسار شقيق.

## أفخاخ وقعنا فيها هنا

- **باريل يخفي الميت:** `actions/index.ts` كان يعيد تصدير ١١ دالّة، فبدت كلها «مستعملة».
  الميت الحقيقي ظهر فقط عند تتبّع المستهلك الفعلي لكل واحدة.
- **بحث ضيّق يصنع ميتاً وهمياً:** `isPublicArticle` بدت بلا مستهلك لأن البحث استثنى
  مجلد `actions/` — ومستهلكها الوحيد كان داخله. كِدنا نحذف ملفاً حيّاً.
- **اسم يصف تقنية لا شيئاً مرئياً:** `client-lazy.tsx` كان سلّة أغلفة `ssr:false`.
  صار كل غلاف بجانب مكوّنه بلاحقة `Lazy`.
- **`article-lab-*`:** ستّة مكوّنات إنتاجية تحمل اسم «مختبر». أُعيدت تسميتها لما يراه الزائر.
- **بارامتر يُمرَّر ولا يُستعمل:** الشاشة كانت تمرّر `userId` إلى `getArticleComments`
  والدالّة لا تقرأه — حُذف من الطرفين.
