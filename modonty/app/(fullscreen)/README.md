# `(fullscreen)` — صفحات بلا هيدر ولا فوتر

مجموعة مسارات (route group): اسمها بين قوسين فلا يدخل الرابط — `/reels` يبقى `/reels`.

## لماذا وُجدت (٢٤ أغسطس ٢٠٢٦)

صفحة الطلّات تملأ الشاشة (`h-dvh` + `snap-y`) وتغطّي كروم الموقع تماماً. وهي كانت تحت
`app/(site)/`، فكان `SiteShell` يرسم الهيدر والفوتر **خلفها**: غير مرئيين، لكن موجودين.

القياس الحيّ الذي أثبت الضرر (`/reels`، الأربعاء ٢٤ أغسطس):

```
390×844   focusableTotal 50 · buriedFocusable 18 · footerRect { y:330, h:515 }
1280×800  header h=0 · footer h=292 (مغطّى) · buriedFocusable 18
```

ثمانية عشر رابطاً غير مرئيّ يمرّ عليها **الكيبورد وقارئ الشاشة** قبل أن تصل إلى الطلّة،
ومعها حزمة الناف بار والفوتر تُحمّل على صفحة لا تعرضهما.

## القاعدة

صفحةٌ تغطّي الشاشة كلّها بتصميمها تسكن هنا، لا تحت `(site)`. إخفاء الكروم بـCSS لا يكفي:
العنصر المخفيّ بصرياً يبقى في شجرة الوصول وترتيب التركيز ما لم يُحذف من الـDOM.

المجموعة بلا `layout.tsx` عمداً — فترث `app/layout.tsx` وحده (html · body · مزوّدات).
وكل مسار هنا يحمل `error.tsx` الخاص به لأنه خرج من حدّ خطأ `(site)`.
