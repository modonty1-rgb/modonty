متى نقول إن النسخة نجحت؟

النجاح ليس أن الشاشة تفتح: العميل يسجّل دخولًا، يرى بيانات كيما زون فقط، يقرأ مقاله، يوافق أو يطلب تعديلًا مع نتيجة محفوظة، ويرى جمهورًا حقيقيًا. بعدها نكمل API الحجوزات والفيديو، ثم التنبيهات كآخر مرحلة.

هذا الملف يصف الوضع الفعلي في قاعدة التطوير وقت الفحص. لا يحتوي كلمات مرور أو بيانات زوار شخصية.
