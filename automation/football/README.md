# Football feed — صفحة «الكورة» في مدونتي

| | |
|---|---|
| يعمل على | Contabo `84.46.245.226` · `/opt/football` · venv الرادار (`/opt/content-radar/venv`) |
| التشغيل | كل دقيقة (cron + flock) — يقرّر بنفسه: وقت المباريات كل دقيقة/٤ دقائق، وباقي اليوم كل ساعة |
| المخرَج | صفحة جاهزة ← الأدمن `/api/football/ingest` (سرّ `RADAR_INGEST_SECRET`) ← صفّ `football:page:v1` في `feed_snapshots` ← مدونتي تقرأه فقط |
| الأسرار | من `/opt/content-radar/.env` (`RADAR_ADMIN_URL` · `RADAR_INGEST_SECRET`) — لا سرّ جديد |

مدونتي لا تتّصل بأي مصدر خارجي (خالد ١٥ أكتوبر ٢٠٢٦: «ما نأثر على مدونتي»).

## المصدران (مجانيان · بلا مفتاح · بالعربي — مقيسان ١٥ أكتوبر ٢٠٢٦)

| المصدر | ما نأخذه منه |
|---|---|
| الموقع الرسمي لدوري روشن `api-sdp.spl.com.sa` (Opta) | المباريات · النتيجة الرسمية · الترتيب · الشعارات · الهدّافون (٢١ صفحة تُجمع) |
| 365Scores `webws.365scores.com` | الدقيقة الحيّة · التأجيل · رقم الجولة · قائمة الهدّافين للمطابقة |

كلاهما API داخلي لموقع صاحبه، لا منشور للغير: قد يتغيّر. آخر نسخة سليمة تبقى في `state.json` وفي الصفّ.

## قاعدة المطابقة

- النتيجة النهائية تُعرض حين يتّفق المصدران؛ غير ذلك «انتهت · النتيجة بانتظار التأكيد» بلا أرقام.
- الحيّ والتأجيل من 365Scores وحده (الرسمي لا يبثّهما).
- الهدّافون: عدد اللاعبين لكل (نادٍ، أهداف) متساوٍ في المصدرين لمن بلغ أهداف الخامس — وإلا لا قائمة.
  (الإملاء يختلف بين المصدرين: «ريتيغي» · «ريتيجي».)
