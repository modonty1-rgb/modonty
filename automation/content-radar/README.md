## المجالات والمصادر

| المجال | المصدر | الحالة |
|---|---|---|
| القطاعات · الأقسام · الصناعات (من القاعدة) | اقتراحات بحث قوقل SA + أخبار قوقل الأسبوع | يعمل |
| المنافسون (يعدّلهم الفريق من الصفحة) | أخبار قوقل `site:<النطاق> when:7d` | يعمل — موسوعات المحتوى قد تُرصد صفراً |
| عام | قوقل ترندز SA | يعمل |
| يوتيوب | — | شِيل (خالد ١٥ أكتوبر ٢٠٢٦: أغانٍ وترفيه، لا نيّة بحث) |
| X | `X_ENABLED=1` | **مطفأ** — رصيد X $0 |

«فرص قوقل» · «مودو» · «أسئلة القرّاء» · «المواسم» · «النتائج» تُقرأ في الأدمن مباشرةً — لا رادار ولا توكن.

## متغيّرات السيرفر (`/opt/content-radar/.env` · 600 · لا تُرفع)

`RADAR_ADMIN_URL=https://admin.modonty.com` · `RADAR_INGEST_SECRET` (نفس قيمة Vercel الأدمن) · `ANTHROPIC_API_KEY`.
اختيارية: `RADAR_ONLY_FIELD` (`type:key` أو `type`) · `RADAR_WORKERS` · `RADAR_IDEAS_PER_FIELD` · `RADAR_MIN_RELEVANCE`.
